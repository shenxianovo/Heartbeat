# ADR-0006：底层记录模型承担同一份结果的更正语义

## 状态：已接受

## 日期：2026-09-14

## 背景

当前写入链路允许任意 JSON，但固定同一 Record 的值和开始时间，仅允许明确区间延长。该约束使持续状态的重复、乱序和迟到上传容易收敛，却不能自然表达另一类需求：来源对同一份历史结果的更正。

用户确认，某日步数从 6000 修正为 5500 属于同一份结果的更正，而非两份独立结果。读取只需当前有效结果，不要求查询每次读取的旧值。更正可以涉及历史，也可以涉及时间，例如将原记作 09:00–09:30 的活动改为 09:05–09:20。

另一种选择是底层只保存独立快照，让每个协议的读取方自行识别同一份结果并选取有效内容。这保留了简单写入约束，但把共同的结果身份与更正语义留给每个接入方重复补齐。

## 决策

底层记录模型负责区分新增独立结果与更正已有结果，表达同一份结果的更正关系，并为读取方提供当前有效内容。结果的逻辑身份不能仅由当前值或时间范围是否相等来决定。

模型允许更正历史结果的内容和时间，包括数值变小、区间缩短和时间位置改变。固定值、固定开始时间及结束时间只增不能作为所有 Record 的普遍领域不变量。

ADR-0002 的单调区间延长仍是持续状态续期的有效规则；本决定调整的是将该规则作为通用结果更新边界的适用范围。

本决定仅确定模型含义和职责，不选择修改接口、版本字段、物理覆盖或追加存储方式，也不要求每个 Collector 提供修改功能。如何判定修正的新旧、处理重传与旧回执、应用更正以及维护查询一致性，留待具体设计；不以数值更大或消息最后到达替代这些设计。

## 后果

- 同一份结果的身份与当前内容可以区分，新的可更正数据不必各自承担完整的更正语义。
- 若采用追加存储，仍须表达同一结果及其更正关系；仅生成无关联的新 Record 不满足本决定。
- 底层会承担当前有效内容选择的共同规则，需要在实施前设计并验证。
- 当前代码仍执行 ADR-0002 的有限更新规则，尚未实现本决定；macOS system 恢复范围不会因此自动扩大。
- 本轮不要求旧值历史查询，不展开前端人工纠错、撤回或结果拆分合并的语义。
