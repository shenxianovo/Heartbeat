# ADR-0017：原生桌面 UI 共用平台无关的运行模块

## 状态：已接受

## 日期：2026-09-20

用户决定废弃 Avalonia，由 Windows 的 WinUI 3/C# 与 macOS 的 AppKit/C# 分别维护原生界面，共享 `Heartbeat.Desktop`。桌面主要承载配置、采集状态及常驻入口，回放继续由 Web 承载；接受两套 UI、平台构建与交互验收的维护成本，以直接表达各平台的窗口、菜单栏或托盘和应用生命周期。

本决策替代 ADR-0016 的 Avalonia 选择，保留其 Hub 组合、凭据权威和暂停/退出语义。共享运行模块负责配置认证、采集与 Hub 启停、操作串行化、启动恢复及运行状态；平台宿主负责窗口、布局、文案、主线程调度和系统生命周期适配。窗口开关不触发采集恢复，应用启动显式初始化一次，用户暂停后重新打开窗口仍保持暂停。

平台能力通过现有接口注入，原生采集与共享投影继续遵循 ADR-0015。共享运行模块不得引用 WinUI、AppKit 或任一平台宿主，也不共享 UI ViewModel。系统权限请求及设置跳转由原生宿主调用平台适配；共享采集管线仍负责报告观测能力。平台宿主在最终退出前等待共享运行模块停止，退出不等待网络队列排空。

迁移删除 Avalonia，两套原生宿主分别实现与验收。每个平台使用自身 SDK 和打包入口，共享逻辑测试不替代平台构建及真实 UI 验收；本次不建设 CI 或上线分发。
