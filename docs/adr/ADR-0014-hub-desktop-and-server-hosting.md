# ADR-0014：Hub 同时支持客户端和服务器部署

## 状态：已接受

## 日期：2026-09-20

## 背景

恢复跨平台客户端时，需要明确 Hub 的部署位置。ADR-0009 将 Hub 描述为本机组件，当前开发环境则通过 Compose 运行 Hub。用户明确要求两种部署方式：Hub 可以随客户端运行，也可以部署在远端服务器；当所有客户端离线时，服务器侧仍需运行微信步数、VRChat 等 Collector。

## 决策

Hub 是所有 Collector 共用的交付能力，支持客户端和服务器两种部署方式。部署位置不改变“Collector 采集、Hub 交付、后端存储、前端展示”的责任划分。服务器上的采集仍由对应 Collector 实现，Hub 不依赖具名的可选 Collector。

本决策修正 ADR-0009 对部署位置的本机限定，保留其持久接管、注册、Track 映射和上传责任。SQLite 接管发生在运行该 Hub 的主机上。客户端与服务器上的 Hub 各自直接向后端交付，不通过另一处 Hub 转发。

## 后果

- 跨平台客户端应复用 Hub 能力，Hub 的核心实现不依赖桌面 UI 或 macOS。
- 服务器侧采集不依赖桌面客户端在线。
- Collector 如何安装与启停、桌面宿主的进程组合由具体宿主设计确定。
