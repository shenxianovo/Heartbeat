设计主张

把 Heartbeat 做成一台动态记录仪

动态心电记录仪连续记录 24 小时，医生事后逐段回放；每条导联各自成立，信号脱落就标成脱落。Heartbeat 做的事情一模一样：长期采集、事后回放、来源分立、空白即未知。界面直接借用这台仪器的语言：记录纸网格、通道、刻度和走纸。

三条规矩

领域约束直接画进界面

CONTEXT.md 里最容易被界面说错的三件事，各自对应一个固定的视觉记号。全站只用这一套记号。

通道分立

每个 Collector 是一条带颜色的通道，时长只在通道内取并集。不同通道永远并排，不出现跨来源总时长。

空白就是未知

没有观测画成斜线格“无观测”；锁屏、休眠这类离开信号画成虚点线。两者都不画成零，也不和前后区间连起来。

时间有刻度

记录纸网格就是时间轴本身：大格、小格随缩放切换到 1 时 / 10 分、10 分 / 1 分。时间和数字一律等宽字。

概览：一份记录报告

气泡图只能比大小，读不出哪天有、哪天没有。改成每个来源一条通道，按天出柱，右侧给出这条通道自己的合计。没有记录的日子画斜线格。

范围

改什么，留什么

保留

  • 路由、数据流、查询缓存与 ADR-0011/0012 的责任划分
  • uPlot 画布泳道与拖动性能基准，只换配色和网格
  • Record renderer 注册表、安全 JSON、键盘操作
  • shadcn 组件骨架，换成新 token

替换

  • tokens.css：冷蓝玻璃 → 记录纸 / 监护仪两套
  • 概览气泡 → 通道日柱报告
  • VRChat 世界气泡 → 刻度条排行
  • 页头：独立导航（概览 · 时间线 · VRChat · Hub）＋ Hub 在线摘要
  • 字体：系统字 → 思源宋体 / 思源黑体 / Plex Mono（next/font 自托管）

移除

  • 毛玻璃、背景光晕、大圆角卡片
  • 数据页背后的看板娘（见下方第 1 问）
  • 气泡圆形展开转场，改成通道条展开
  • globals.css 里各页私有的重复样式
需要你拍板

开工前的四个问题

  1. 看板娘放哪里

    建议只留在登录页和空状态，数据页不再垫在图表后面。也可以完全保留现状或彻底去掉。

  2. 气泡要不要彻底退役

    建议概览和 VRChat 都换成通道条；圆形展开转场随之改成通道条展开。如果你喜欢气泡的感觉，可以保留 VRChat 世界气泡作为“地图视图”。

  3. 字体加载

    中文网字体会增加首屏体积。next/font 按 unicode-range 分片自托管，只在用到的字上下载；不接受的话回退到系统宋体 / 苹方。

  4. 实施顺序

    建议先换 token 和页头（全站立刻统一），再依次做概览、时间线、VRChat、Hub，每步都跑 replay-fixture 和截图。
