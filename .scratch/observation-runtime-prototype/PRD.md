# Browser 临时 FOI：运行逻辑验证

Status: done

范围：用现有 Browser fold 验证临时窗口对象是否足以管理并行活动，并保留活动输出。
本项只完成运行逻辑演练及可试用原型，不包含生产 Collector 改造、SDK、数据库、页面视觉验收或真实浏览器采集验收。

- [x] 复用实际 fold.ts，不另建通用对象注册或关系模块。
- [x] 演练两个窗口并行、页面切换、关闭后另开窗口，记录每步状态和输出。
- [x] 生成无外部依赖、双击打开的单文件 HTML；脚本语法检查通过。
- [x] 原型保存到独立分支，主工作区只保留模型决定和证据指针。

记录：[01 — 运行逻辑与结论](issues/01-browser-ephemeral-foi.md)。
UI 限制：内置浏览器安全策略拒绝打开本地 HTML，本轮没有验证页面点击或视觉呈现；
逻辑结论来自实际 fold 的命令行演练，不能将其描述为浏览器 UI 测试通过。

本原型的结论是无需先把窗口注册为持久实体；不据此推断全部观测来源都无需任何长期身份。
