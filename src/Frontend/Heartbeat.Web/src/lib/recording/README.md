# 观测时间计算

这里复用 Web 对已读取 Record 的时间计算。查询、协议解释和显示责任仍沿用 ADR-0004、ADR-0011/0012；本模块不读取 `value`、不持有缓存、不修改 Record。

- `clipExplicitRange` 把显式区间裁到半开窗口 `[from, to)`，返回毫秒区间或 `null`。非法时间、反向区间、空窗口以及没有明确结束的 Record 不参与计算。非零区间仅接触窗口边界时被排除；零时长观测按其时间位置纳入，贡献零时长。缺少 `endedAt` 不代表持续到现在，也不推导 `next_record` 的结束。
- `coveredMilliseconds` 接收有效的有限区间（`from <= to`），计算并集覆盖时长。调用方先用裁剪结果确定有效区间，再按业务选择参与计算的来源或分组。乱序、重叠、嵌套和重复区间不重复计时；观测空白保留；输入数组及对象不被修改。

概览按单个 Collector 计算覆盖时长。VRChat 复用裁剪，但世界、同场对象、实例类型的分组及逐观测段累计仍由该视图决定；不能把不同来源或不同对象自动合成“人的总活动时长”。显示文案放在 `lib/dates.ts`，与时间计算分离。

只增加实际调用方需要的操作，不预设查询语言、空白填补、活动推定或派生 Track 的存储机制。纯函数测试覆盖数值与窗口规则，不能证明真实 Collector 的观测完整性。
