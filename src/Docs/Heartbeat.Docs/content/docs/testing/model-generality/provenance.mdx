[下载全部 100 个场景的完整 JSON](/model-stress/scenarios.json)，按本页编号查找，可以检查精确 Schema、输入、身份规则、时间和重放约定。

实际覆盖与限制见[验证证据](./evidence.mdx)。字段能存下来，不代表自动满足领域约束、历史保真或图查询。

## 怎么读这些结果

这些映射没有依靠一个万能原始 JSON 字段把所有问题藏起来。来源标识、原始时间、状态、顺序和关系都有声明过的业务字段；确实需要保留字节时，才用明确的编码。

如果一个来源没有提供历史正文、结束事件、时区或准确到达时间，测试不会替它补造。映射成功也不表示来源鉴权、生产采集、查询性能或长期运行已经验证。
