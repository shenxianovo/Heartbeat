Heartbeat 使用 TUnit 执行测试。模型定义见 [Heartbeat Core](../core/index.mdx)，读写协议见 [Heartbeat API](../api/index.mdx)，数据库结构见 [Heartbeat Storage](../storage/index.mdx)。

## 测试分工

| 类型 | 验证内容 | 数据库 |
| --- | --- | --- |
| 单元测试 | 独立规则与转换逻辑 | 不启动数据库 |
| 集成测试 | 采集程序、后端组件与 PostgreSQL 的协作 | 使用独立测试数据库 |
| 端到端测试 | 完整用户操作流程 | 需要数据库的用例使用独立测试数据库 |

## 测试框架与公共工具

TUnit 通过 Microsoft.Testing.Platform 运行，版本 `1.72.16` 由 `Directory.Packages.props` 管理。

`tests/Heartbeat.Testing` 为集成测试和端到端测试提供数据库工具。类库使用 `Heartbeat.Testing` 命名空间，每个类型一个文件。依赖包含 Infrastructure、EF Core、Npgsql 和 Testcontainers.PostgreSql，版本由 `Directory.Packages.props` 管理。

| 类型 | 职责 |
| --- | --- |
| `PostgresTestInstance` | 启动和销毁 PostgreSQL 容器，创建用例数据库 |
| `TestDatabase` | 提供连接字符串，释放时删除用例数据库 |

测试框架调用工具的生命周期方法。集成测试和端到端测试各自创建独立实例，规则见[测试数据库](./database.mdx)。组件职责见 [ADR 0005](../adr/0005-backend-project-organization.mdx#测试数据库)。

## 当前验证边界

集成测试项目位于 `tests/Heartbeat.Integration.Tests`。数据库用例使用真实 PostgreSQL 和 Infrastructure 迁移。

HTTP 用例通过 `WebApplicationFactory` 启动 API 宿主，使用与服务相同的应用和数据库实现。每个用例通过 `ConnectionStrings:Heartbeat` 提供独立数据库连接。

| 用例范围 | 验证内容 |
| --- | --- |
| 实体持久化 | 保存 Observer 和索引，再从新的上下文读取 |
| 四类实体 HTTP 保存与读取 | 创建、重复提交、替换、类别冲突、无效请求、写入失败回滚和同 ID 并发保存 |
| 通用实体 | 嵌套 JSON、重复键、Unicode 和表示范围 |
| Observation | 未入库的引用、UTC、微秒精度、未知边界与时区 |
| ObservationSchema | 名称与 JSON 更新、任意可存储的 JSON 值、仅含名称和定义的读回内容 |
| 请求体上限 | 真实 Kestrel 接收 10 MiB 请求，超限返回 JSON `413`，支持分块传输 |
| OpenAPI | 请求字段、必填可空时间、成功响应、多类别读取和错误格式 |

专门的读取用例先在数据库中准备内容，再通过 HTTP 断言。OpenAPI 用例读取构建生成的规范，不创建数据库。后端不比较观测定义的语义。

前台状态 Observer 的用例分别检查：

- 身份文件：复用、独立实例、并发创建和损坏文件保留。
- 提交：通过真实 API 和 PostgreSQL 检查快照、引用、微秒时间、重复提交和失败后的实体保留。
- 读回：使用模拟响应，检查类别或内容不一致时报告失败。

自动测试不调用 macOS 原生接口。原生读取需在 macOS 上使用独立 API 和测试数据库运行采集程序。步骤见 `src/Observers/Heartbeat.Observer.ForegroundState/README.md` 的“验证”节。

TUnit 的程序集 `Before`、`After` 钩子管理共享容器。数据库用例的 `Before`、`After` 钩子创建和删除独立数据库。

## 报告

[集成测试报告](./reports/integration.mdx)读取 `TestResults` 中文件修改时间最大的 TUnit 集成测试 JSON。每次刷新重新读取文件；文件不存在时显示尚未生成。

测试 JSON 是结果的权威来源，查看报告不运行测试。文档站使用 `fumadocs-test-reports` 展示报告，提供搜索、状态筛选、详情、输出和追踪时间线。职责见 [ADR 0007](../adr/0007-developer-cli-and-verification.mdx#测试报告)。
