## 为什么验证 [#why]

读取方按类型列出实体，按事实时间找出一段时间内的观测。查询只看当前版本中已知的边界，结果的排序和游标决定翻页时是否重复或遗漏。约定见 [API · 列出与查询](../../api/index.mdx#lists) 和 [分页](../../api/index.mdx#paging)。

## 前置条件 [#setup]

通过 `WebApplicationFactory` 启动 API，连接一个独立的测试数据库，见 [Database](../database.mdx)。先提交一个资源名为 `items` 的 EntitySchema、它的业务实体，以及引用这个业务实体的几份 Observation。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| `GET /entities?resourceName=items` | 只返回 `items` 的业务实体 |
| `GET /entities?category=entity_schema` | 只返回 EntitySchema |
| `GET /entities?resourceName=missing`，没有 EntitySchema 使用这个资源名 | `404` |
| 查询 `[from, to)`，Observation 分别是与范围重叠的时段、范围内的时间点、只知道开始、只知道结束、两个边界都未知 | 返回前四份；两个边界都未知的不返回 |
| 查看上一行的结果顺序 | 按已知的开始边界升序，开始边界未知时用结束边界，相同时按 EntityId 升序 |
| 为其中一份 Observation 提交新版本，把事实时间移出范围，再查询 | 这份 Observation 不再返回 |
| 用 `limit=1` 查询，沿 `next` 作为 `after` 翻到最后一页 | 各页合起来与一次查询全部的结果相同，没有重复；最后一页的 `next` 为 `null` |
