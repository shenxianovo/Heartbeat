## 为什么验证 [#why]

程序退出、崩溃或本地写入失败时，已结束的时段必须完整地留在 Outbox 中，进行中的时段也要能在下次启动时恢复。

## 前置条件 [#setup]

使用独立的 SQLite 文件和模拟的读数。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 保存并延长当前时段 | Outbox 为空，当前时段只在本地更新 |
| 重新打开状态文件，结束遗留的时段 | 以最后一次确认的时间入队，ID 和完整的提交内容保持不变 |
| 再执行一次恢复 | 不重复入队 |
| 另一个 Observer 打开同一个状态文件 | 报错，原数据保留 |
| 切换应用时，在写入新时段前模拟本地失败 | 已结束时段的入队一起回滚，原来的当前时段仍可恢复 |

## 测试实现 [#implementation]

`ForegroundOutboxTests` 验证本地恢复和事务回滚。
