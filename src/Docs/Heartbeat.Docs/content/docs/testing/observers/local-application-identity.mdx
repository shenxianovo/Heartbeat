export const caseId = 'foreground-local-application-identity';

## 为什么验证

[本机应用](../../observers/entities/local-application.mdx)必须在重启后保持身份，同时避免把不同路径或不同设备上的安装合并。

## 前置条件

为测试创建独立登记文件，不读取用户的应用登记文件。

## 操作与预期结果

| 操作 | 预期结果 |
| --- | --- |
| 首次遇到带包标识和路径的应用 | 生成并保存一个应用身份 |
| 重启采集器后读到相同线索 | 复用原身份 |
| 只修改应用名称 | 复用原身份 |
| 修改路径或包标识 | 新建身份 |
| 用另一设备的登记文件读到相同线索 | 新建身份 |
| 缺少路径，同一采集进程内再次读到相同进程及启动时间 | 复用临时身份 |
| 缺少路径，进程或采集器重启 | 新建身份 |
| 多个采集器同时登记三个不同安装 | 每个安装只有一个身份，三个安装均保留 |

## 测试实现

`LocalApplicationIdentityTests` 中的三个身份行为测试关联此 Case。损坏文件保留由同文件的独立测试验证。
