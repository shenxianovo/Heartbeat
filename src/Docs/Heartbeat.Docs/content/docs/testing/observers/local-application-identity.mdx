## 为什么验证 [#why]

[本机应用](../../observers/application-activity/local-application.mdx)的身份要在程序重启后保持不变，同时不同路径或不同设备上的安装要分开。

## 前置条件 [#setup]

为测试创建独立的登记文件，用户自己的登记文件保持不动。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 首次遇到带包标识和路径的应用 | 生成并保存一个身份 |
| 重启前台状态 Observer 后读到相同的线索 | 复用原来的身份 |
| 只修改应用名称 | 复用原来的身份 |
| 修改路径或包标识 | 新建身份 |
| 用另一台设备的登记文件读到相同的线索 | 新建身份 |
| 缺少路径，同一次运行中再次读到相同的进程和启动时间 | 复用临时身份 |
| 缺少路径，进程或前台状态 Observer 重启 | 新建身份 |
| 多个程序实例同时登记三个不同的安装 | 每个安装恰好一个身份，三个都保留 |

## 测试实现 [#implementation]

`LocalApplicationIdentityTests` 中的三个身份行为测试关联这个 Case。登记文件损坏时的保留由同一文件中的另一个测试验证。
