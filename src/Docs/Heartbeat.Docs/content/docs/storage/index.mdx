实体和它的全部版本保存在 PostgreSQL 中。数据库的版本、数据访问和时间的保存方式见 [PostgreSQL](./postgresql.mdx)，数据模型见 [Core](../core/index.mdx)。表结构和索引将按实体与版本模型定义，目前尚未定义。

## 内容的表示 [#content]

- 文本中有空字符时，API 返回 `400`，事务回滚。
- 对象和数组以 `jsonb` 保存，空白和键的顺序不保留。数值必须在 `numeric` 的范围内，字符串中不能有 `\u0000` 或无效的代理对。
- 时间的保存方式见 [PostgreSQL · 时间](./postgresql.mdx#time)。

## 命名 [#naming]

同一个名字在三处使用三种写法：

| 位置 | 格式 | 示例 |
| --- | --- | --- |
| API 字段 | `camelCase` | `observerVersionId` |
| C# 属性 | `PascalCase` | `ObserverVersionId` |
| 表名、列名、约束名、索引名 | `snake_case` | `observer_version_id` |

约束和索引按下表命名：

| 约束或索引 | 规则 | 示例 |
| --- | --- | --- |
| 主键 | `pk_<表名>` | `pk_example_items` |
| 外键 | `fk_<表名>_<目标表>_<列名>` | `fk_example_items_entities_entity_id` |
| 检查 | `ck_<表名>_<内容>` | `ck_example_items_time_order` |
| 唯一索引 | `ux_<表名>_<列名>` | `ux_example_items_resource_name` |
| 普通索引 | `ix_<表名>_<列名>` | `ix_example_items_observer_version_id` |
