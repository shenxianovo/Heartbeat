本内容保存本机应用引用与当时读到的名称，表达“应用 A 处于前台”。Observation 引用内容，并保存时段的事实时间。

## 记录粒度

一个应用连续处于前台的一段活动对应一条 Observation。连续确认补全同一条观测，窗口标题的变化不切开应用时段。

前台时段只表达系统确认的前台应用事实，不表达用户是否活跃。锁屏、休眠与无输入不作为裁剪本记录的业务条件；需要按其他状态筛选或计算时，再组合独立记录，见 [Desktop · 记录维度](../desktop/index.mdx#记录维度)。

## 身份

应用身份、名称或记录时区变化时，采集器结束当前时段并新建内容与 Observation；原内容保持不变。窗口标题变化不切开应用时段。

## 事实时间

连续确认期间，应用身份、名称和时区都不变时，采集器延长同一条 Observation：内容与起始时间不变，结束时间更新为最后一次确认的时刻。这个边界不表示记录已经结束，见 [TIME-4](../../core/rules/time.mdx#time-4)。

| 事件 | 当前时段 | 下一时段 |
| --- | --- | --- |
| 首次确认应用位于前台 | — | 从确认时刻开始 |
| 切换应用、名称变化或时区变化 | 结束于新确认时刻 | 从同一时刻开始 |
| 读取失败、停止采集或采集器退出 | 结束于最后一次确认 | 恢复后新建 |
| 两次确认间隔超过采样间隔的 3 倍 | 结束于最后一次确认 | 从恢复确认时刻开始 |
| 系统时间跳变，无法延续原有时间边界 | 结束于最后一次确认 | 从恢复确认时刻开始 |
| 系统即将休眠 | 结束于最后一次确认 | 唤醒后重新读取，从新确认时刻开始 |

- 起止已知时为 `[startAt, endAt)`；只有一次确认时起止相同，时长为零。
- 应用激活事件触发确认，默认每 1 秒定时确认一次；断开阈值为定时间隔的 3 倍。
- 系统时间倒退或重复时断开。墙上时间的增量与持续计时的增量相差超过 100 毫秒时，同样断开。
- 休眠期间采集器不运行，没有确认证据，所以休眠通知结束当前时段。通知遗漏时，包含休眠和不含休眠的两种计时之差超过 100 毫秒，同样断开。macOS 两种计时的区别见 [Mach 时间接口](https://github.com/apple/darwin-xnu/blob/main/osfmk/mach/mach_time.h)。
- 锁屏和无输入不触发分段。前台时段只记录系统确认的前台应用，不判断用户是否活跃。
- 时段边界使用确认时刻。定时读取只记录当前状态，两次确认之间的切换由应用激活事件补充。
- `TimeZone` 为采集时的本机 IANA 时区，未知时为 `null`。

## Schema

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-000000000001` |
| 显示名称 | 前台应用时段 |
| 说明 | 表达某个本机应用连续处于前台的一段活动；内容保存应用引用与当时读到的名称，Observation 保存时段。 |
| 资源名 | `foreground-application-periods` |

| 字段 | 类型 | 必填 | 可空 | 含义 |
| --- | --- | --- | --- | --- |
| `localApplicationId` | `reference` | 是 | 否 | 观测设备上的本机应用 |
| `name` | `string` | 是 | 是 | 当时读到的应用名称；未取得时为 `null` |

## 示例

`PUT /entities/foreground-application-periods/{id}`：

```json
{
  "references": {
    "localApplicationId": "01a12e31-9050-7000-8000-000000000001"
  },
  "properties": {
    "name": "Visual Studio Code"
  }
}
```
