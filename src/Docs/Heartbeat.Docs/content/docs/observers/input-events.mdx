输入事件 Observer 负责形成键盘和鼠标事件观测，与前台状态、设备状态 Observer 分别拥有自己的实例身份。三者可以运行在同一程序中。职责已确认，具体数据与采集规则仍为草案，尚未实现。

## ObserverId

`ObserverId` 标识一个独立的输入事件采集器实例。实例多次采集、重启或升级时沿用原身份；另一台设备或另一个独立实例使用自己的身份。

键盘和鼠标观测由同一输入事件实例形成时，共用该实例的 `ObserverId`。具体身份生成与本地保存方式尚未确定，不能直接套用前台状态实例的身份文件。

## ObservationSchema

使用[键鼠输入事件](./schemas/input-event.mdx)表达一次输入发生。草案提供按下、释放、移动和滚动等事件类别；实际采集哪些类别、保留哪些细节，需逐项确认。

各平台遵循相同的事件含义、字段和时间规则时，共用一份 Schema。平台读取方式属于采集实现。

## ITimed

一次事件使用时间点 Observation：`StartAt = EndAt = t`，t 表示输入事件发生的时刻。具体时间来源、精度转换和缺失时间的处理尚需确认。

Observer、ObservationSchema 和具体数据只实现 `IEntity`。输入次数的时间段统计不代替逐条事件时间；设备清醒或用户活跃的判断也不由输入事件本身直接表达。

模型时间规则见 [ITimed](../core/model/contracts/timed.mdx)，组件职责见 [ADR 0002](../adr/0002-observer-capabilities-and-platform-clients.mdx#桌面观测职责)。
