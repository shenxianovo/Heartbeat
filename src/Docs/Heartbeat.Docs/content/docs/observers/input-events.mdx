输入事件 Observer 形成键盘和鼠标事件观测。输入事件、前台状态和设备状态 Observer 分别拥有实例身份。三个 Observer 可以运行在同一程序中。

数据字段与采集规则仍为草案。输入事件采集尚未实现。

## ObserverId

`ObserverId` 标识一个独立的输入事件采集器实例。同一实例多次采集、重启或升级时，采集器沿用原身份。另一台设备或独立实例使用自己的身份。

如果键盘和鼠标观测由同一实例形成，两类观测共用 `ObserverId`。具体身份生成与本地保存方式尚未确定，不能直接套用前台状态实例的身份文件。

## EntitySchema

[键鼠输入事件](./schemas/input-event.mdx)定义一次输入事件。草案包含键盘按下、键盘释放、鼠标按钮按下、鼠标按钮释放、鼠标移动和鼠标滚动。采集类别和数据字段需逐项确认。

各平台遵循相同的事件含义、字段和时间规则时，共用一份 EntitySchema。平台读取方式属于采集实现。

## ITimed

一次事件使用时间点 Observation：`StartAt = EndAt = t`，t 表示输入事件发生的时刻。具体时间来源、精度转换和缺失时间的处理尚需确认。

Observer、EntitySchema 和观测内容只实现 `IEntity`。输入次数的区间统计不代替逐条事件。输入事件不直接表达设备清醒或用户活跃。

模型时间规则见 [ITimed](../core/model/contracts/timed.mdx)，组件职责见 [ADR 0002](../adr/0002-observer-capabilities-and-platform-clients.mdx#桌面观测职责)。
