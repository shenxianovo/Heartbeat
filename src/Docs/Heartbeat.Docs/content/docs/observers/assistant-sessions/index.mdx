---
title: "Assistant Sessions"
description: "助手会话、执行与工具调用"
---

保存助手会话历史，以及来源提供的执行、工具调用和输出。会话文字与执行证据分别记录。尚无原生适配器，也未登记 Schema；接入前需要确定来源版本。

## 实体

| 实体 | 含义 | 身份 | 需要保留的信息 |
| --- | --- | --- | --- |
| 助手会话 | 来源定义的一段逻辑会话 | 来源 `session_id`；真正的分叉有自己的会话身份，文件副本不产生新会话 | 标识范围；分叉来源与已知分叉时间 |
| 会话记录 | 一条消息或记录发生项 | 按来源记录身份；相同文本可以是不同记录 | 所属会话；记录种类；来源顺序；事实时间 |
| 助手执行 | 来源能证明的一次执行 | 按来源执行或 trace/span 标识；并发执行分别识别 | 父执行；输入输出；执行边界 |
| 工具调用 | 一次逻辑工具调用 | 来源调用标识；传输重试不产生新调用 | 父执行；工具名称；参数与输出 |
| 执行尝试 | 逻辑调用的一次实际执行 | 来源 attempt 标识；重执行产生新尝试 | 所属调用；状态；执行边界 |
| 输出项 | 流式协议标识的一项输出 | 来源 `item_id` | `output_index`、内容位置；完整输出 |
| 流式增量 | 输出逐步形成时的一段增量 | 流实例与 `sequence_number` | 所属输出项；`content_index`；增量内容 |

## 形成规则

- 只读取完整记录；末尾未写完的行留到下次读取。
- 历史消息和分叉使用来源记录的时间；来源没有时间时为 `null`。
- 流式增量用序号表达顺序，序号不换算成时刻。
