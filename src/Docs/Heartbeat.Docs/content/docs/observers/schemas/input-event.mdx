本定义表达“时刻 t 发生一次键盘或鼠标事件”。[输入事件 Observer](../input-events.mdx)负责形成观测。

字段与事件类别仍为草案。输入事件采集尚未实现，固定 SchemaId 尚未分配。

## 数据结构

观测内容只实现 `IEntity`。Observation 保存事件时间。草案用一个字段记录事件类别：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `kind` | 字符串枚举 | 发生的输入事件类别 |

| `kind` | 含义 |
| --- | --- |
| `keyDown` | 键盘按下 |
| `keyUp` | 键盘释放 |
| `mouseDown` | 鼠标按钮按下 |
| `mouseUp` | 鼠标按钮释放 |
| `mouseMove` | 鼠标移动 |
| `mouseWheel` | 鼠标滚动 |

`kind` 表达跨平台事件类别，不保存系统 API 常量。采集哪些类别，是否保留按键、按钮、坐标或滚动量，尚需确认。

### 数据示例

以下示例只展示观测内容。实体 ID 和 Observation 的引用、时间字段不在示例中。

数组展示六种草案值。每条事件观测只引用其中一个对象作为观测内容。

```json
[
  { "kind": "keyDown" },
  { "kind": "keyUp" },
  { "kind": "mouseDown" },
  { "kind": "mouseUp" },

  { "kind": "mouseWheel" }
]
```

## 事实时间

每次事件使用时间点 Observation：`StartAt = EndAt = t`。如果两次同类事件发生在不同时刻，分别形成两条观测。

以下规则尚需确认：

- 使用系统事件时间还是采集器接收时间。
- 时间精度的转换方式。
- 键盘自动重复、鼠标移动和滚动的记录粒度。

输入次数的区间统计不能恢复每次事件的发生时刻。区间统计不代替本定义。时间契约见 [ITimed](../../core/model/contracts/timed.mdx#边界语义)。

## 定义与实现状态

各平台遵循同一事件含义、字段和时间规则时，共用一份定义。字段、约束和采集规则需确认后实施。
