本定义表达“时刻 t 发生一次键盘或鼠标事件”，由[输入事件 Observer](../input-events.mdx)形成观测。时间点粒度已确认，以下字段与采集类别为草案。尚未实现，固定 SchemaId 尚未分配。

## 数据结构

Data 只实现 `IEntity`，事件时间由 Observation 保存。最小草案用一个字段记录事件类别：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `kind` | 字符串枚举 | 发生的输入事件类别 |

| `kind` | 含义 |
| --- | --- |
| `keyDown` | 键盘按下 |
| `keyUp` | 键盘释放 |
| `mouseDown` | 鼠标按钮按下 |
| `mouseUp` | 鼠标按钮释放 |
| `mouseMove` | 鼠标移动 |
| `mouseWheel` | 鼠标滚动 |

这些类别描述跨平台事件含义，不直接保存系统 API 常量。实际采集哪些类别、是否保留具体按键、按钮、坐标或滚动量，尚需确认。

### JSON 结构草案

以下定义描述具体数据内容，不包含 `IEntity.Id` 或 Observation 的身份、时间字段。

```json
{
  "type": "object",
  "properties": {
    "kind": {
      "type": "string",
      "enum": ["keyDown", "keyUp", "mouseDown", "mouseUp", "mouseMove", "mouseWheel"]
    }
  },
  "required": ["kind"],
  "additionalProperties": false
}
```

### 数据示例

```json
{
  "kind": "keyDown"
}
```

## 事实时间

每次事件使用时间点 Observation：`StartAt = EndAt = t`。两次同类事件发生在不同时刻时，仍分别表示两次事件，不延长为一个持续状态。

时间来自系统事件还是采集器接收时刻、时间精度如何转换，尚需确认。键盘自动重复、鼠标移动和滚动的记录粒度也需确认。

时间段输入次数统计不能恢复每次事件的发生时刻，不代替本定义。时间契约见 [ITimed](../../core/model/contracts/timed.mdx#边界语义)。
