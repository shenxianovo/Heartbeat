本定义表达“前台窗口显示标题 T 的时段”，由[前台状态 Observer](../foreground-state.mdx)形成观测。应用和标题观测共用实例身份，各自使用自己的 Schema 与时间线。本页为数据结构草案，尚未实现，固定 SchemaId 尚未分配。

## 数据结构

Data 只实现 `IEntity`，起止时间由 Observation 保存。最小草案只保存读到的标题：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `title` | 字符串 | 来源提供的前台窗口标题，保留原始内容 |

本草案允许已成功读取的空标题 `""`。读取失败与空标题如何区分、未知标题是否另有表达方式，尚需确认。

### JSON 结构草案

以下定义描述具体数据内容，不包含 `IEntity.Id` 或 Observation 的身份、时间字段。

```json
{
  "type": "object",
  "properties": {
    "title": { "type": "string" }
  },
  "required": ["title"],
  "additionalProperties": false
}
```

### 数据示例

```json
{
  "title": "README.md — Visual Studio Code"
}
```

标题保留来源文字，不在这里解析文件、项目或网页身份。若另一个主体解释标题并形成新事实，新观测引用该主体的 ObserverId。

## 事实时间

标题使用时间段 Observation，与应用时间线独立。标题变化不切开应用时段；标题读取失败时，应用仍可形成观测。

标题时段的开始、切换、读取失败与采集空白处理尚需确认。切换应用但标题文字相同的情况，以及标题与应用时段如何关联，也需确认。

已知起止边界的时段遵循 [ITimed](../../core/model/contracts/timed.mdx#边界语义) 的左闭右开区间规则。未知结束不证明标题此刻仍在前台。

## 定义与实现状态

跨平台实现遵循同一字段与时间含义时，共用一份定义。标题读取方式、权限和系统 API 留在具体平台实现中。

当前程序只读取应用，未采集标题。本页字段、约束和时段规则需确认后实施。
