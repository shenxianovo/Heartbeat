本定义表达“前台窗口显示标题 T 的时段”。[前台状态 Observer](../foreground-state.mdx)负责形成观测。应用和标题观测共用实例身份，分别使用自己的实体定义和时间线。

字段与时段规则仍为草案。标题采集尚未实现，固定 SchemaId 尚未分配。

## 数据结构

观测内容只实现 `IEntity`。Observation 保存起止时间。草案只保存读到的标题：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `title` | 字符串 | 来源提供的前台窗口标题，保留原始内容 |

### 数据示例

以下示例只展示观测内容。实体 ID 和 Observation 的引用、时间字段不在示例中。

```json
{
  "title": "README.md — Visual Studio Code"
}
```

成功读取到空标题时，草案使用空字符串：

```json
{
  "title": ""
}
```

空标题与读取失败的具体区分规则仍需确认。

标题保留来源文字，不解析文件、项目或网页身份。如果另一个主体解释标题并形成新事实，新观测使用该解释主体的 `ObserverId`。

## 事实时间

标题使用时间段 Observation。标题时间线独立于应用时间线。标题变化不切开应用时段。如果标题读取失败，仍可形成应用观测。

以下规则尚需确认：

- 标题时段的开始与结束边界。
- 读取失败与采集停顿的处理方式。
- 切换应用但标题相同时是否分段。
- 标题时段与应用时段的关联方式。

已知起止边界的时段遵循 [ITimed](../../core/model/contracts/timed.mdx#边界语义) 的左闭右开区间规则。未知结束不证明标题此刻仍在前台。

## 定义与实现状态

跨平台实现遵循同一字段与时间含义时，共用一份定义。标题读取方式、权限和系统 API 留在具体平台实现中。

当前程序只读取应用，尚未采集标题。
