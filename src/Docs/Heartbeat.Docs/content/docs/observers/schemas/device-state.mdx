本定义表达“设备处于休眠或清醒状态的时段”。[设备状态 Observer](../device-state.mdx)负责形成观测。

字段与时段边界仍为草案。设备状态采集尚未实现，固定 SchemaId 尚未分配。

## 数据结构

观测内容只实现 `IEntity`。Observation 保存状态时间。草案用一个字段记录状态：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `state` | 字符串枚举 | `awake` 表示设备清醒，`asleep` 表示设备休眠 |

`awake` 只表示设备清醒。`awake` 不证明会话未锁定、存在输入或用户正在使用。

如果没有状态证据，状态必须保持未知。采集器不得仅凭没有读数或输入生成休眠观测。

## 事实时间

Observation 保存状态的起止边界。如果两个边界均已知，时段使用左闭右开区间 `[StartAt, EndAt)`。未知边界遵循 [ITimed](../../core/model/contracts/timed.mdx#边界语义)。`EndAt = null` 只表示结束时间未知。

以下规则尚需确认：

- 如何用系统休眠或唤醒证据确定边界。
- 程序启动时如何取得状态。
- 程序崩溃或停止后的采集空白如何处理。

状态观测不得使用提交时间补齐历史边界。

## 定义与实现状态

各平台遵循同一状态含义、字段和时间规则时，共用一份定义。字段、约束与边界规则需确认后实施。锁屏和用户活跃规则另行确认。
