title: "Audio"
description: "音频材料、片段与说话人标注"
---

保存已有音频材料，以及来源提供的片段、轨道和说话人标注。尚无采集入口，也未登记 Schema。

## 实体

| 实体 | 含义 | 身份 | 需要保留的信息 |
| --- | --- | --- | --- |
| 音频材料 | 一份具有来源身份的音频 | 复用已识别材料；文件副本和重新录制按来源证据区分 | 原始材料与标注来源；可靠的录制起点及精度；已取得文件时关联文件快照 |
| 音频片段 | 一份材料中的一段相对范围 | 按来源分段结果识别；同一范围的不同标注各自保留来源 | 所属材料；起点、终点与单位 |
| 轨道 | 来源给出的音频轨道 | 在材料或标注运行范围内复用 | 所属材料与标注来源 |
| 说话人簇 | 来源给出的说话人分组 | 在材料或标注运行范围内复用；不合并为真实人物 | 所属材料与标注来源 |

## 事实时间

片段位置是相对音频起点的偏移。有可靠录制起点时换算 Observation 的绝对边界，否则边界为 `null`。重叠讲话形成相交的片段。
