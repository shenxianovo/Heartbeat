前台状态 Observer 负责应用和窗口标题两类观测。同一实例共用 `ObserverId`，两类观测分别使用自己的实体定义和时间线。标题变化不改变应用的前台状态；标题读取失败不影响应用观测。

## ObserverId

`ObserverId` 标识本机的一个前台状态采集器实例。同一实例多次采集、重启或升级时沿用原 ID。另一台设备或独立实例使用自己的身份。

本地身份文件保存实例 ID。文件不存在时，程序生成 UUIDv7。文件损坏时，程序报告错误并保留原文件。启动参数 `--identity-file` 指定该文件。同一身份文件只允许一个采集进程运行。

本机应用身份使用独立登记文件。同一设备的不同 Observer 实例可以复用同一应用身份。识别与升级规则见[本机应用](./entities/local-application.mdx)。

## EntitySchema

本机应用与观测内容分别登记定义：

| 定义 | 保存内容 |
| --- | --- |
| [本机应用](./entities/local-application.mdx#实体定义与保存) | 应用安装的原生标识线索 |
| [前台应用时段](./schemas/foreground-application-interval.mdx) | 本机应用引用和当时读到的名称 |
| [前台窗口标题时段](./schemas/foreground-window-title.mdx) | 前台窗口标题，具有独立时间线 |

相同业务结构与时间含义的平台实现共用定义。平台读取方式由采集程序负责。

## ITimed

Observation 保存应用处于前台的起止时间。Observer、本机应用、EntitySchema 和观测内容只实现 IEntity。

事实时间以 UTC 保存，精度为微秒。`TimeZone` 保存采集时的本机 IANA 时区，例如 `Asia/Shanghai`；未知时为 `null`。

### 前台应用时段

首次确认时开始记录。连续采集且应用、名称和时区不变时，延长原时段。确认变化时，结束原时段并新开一段。

遇到读取失败、休眠、采集停顿或时间跳变时，保留最后一次确认的位置，恢复后新开一段。停止采集不延长时段。默认采样间隔和断开阈值见[事实时间](./schemas/foreground-application-interval.mdx#事实时间)。

## 采集与本地保存

应用激活事件触发读取。程序默认每秒再确认一次，用于延长当前时段，并发现遗漏的切换。休眠通知结束当前时段；唤醒后重新读取并开始新时段。计时差检查用于补充发现遗漏的休眠或采集中断。

SQLite 分别保存当前时段和 Outbox。当前时段随确认结果更新，只保存在本地。时段结束后，程序把完整提交内容放入 Outbox，此后不再修改。切换时，关闭旧时段、写入 Outbox 和保存新时段在同一本地事务中完成。

停止采集时，当前时段结束于最后一次本地确认。异常退出后，程序在下次启动时按已保存的边界结束遗留时段，再开始采集。停机期间不计入时段。

## 后台发送

后台每轮处理 Outbox 中的已结束时段，依次查询 Observer、应用时段定义、本机应用定义、本机应用、观测内容和 Observation。查询使用统一实体读取入口；缺少的实体通过对应保存入口提交。多个 HTTP 请求不构成一个事务。

发送完成后，记录仍保留在 Outbox。后续轮次读回六个实体，核对类别、引用和属性；全部一致后才删除本地 Outbox 记录。后端已有部分实体时，只提交缺少的实体。同一 ID 的内容不一致时，程序保留本地记录并报告原因，不覆盖后端内容。

每轮处理结束后等待 5 秒。单次请求最多等待 30 秒。断网、请求失败或返回内容不符时，Outbox 保留记录，后续轮次继续查询。网络发送不阻塞采集。读取前台应用失败时，程序结束当前时段，下次确认时继续；本地文件写入失败时停止运行并报告错误。

## 运行范围

macOS 程序通过 AppKit 读取前台应用，支持持续采集和指定采样次数。窗口标题、输入事件、Windows 读取与独立设备状态时间线另行实现。休眠判断在此只用于断开应用时间线。
