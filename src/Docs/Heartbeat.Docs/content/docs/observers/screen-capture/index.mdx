捕获像素和解释图像是两件事：捕获记下取得了哪一片画面；OCR 和对象检测各自记下一次识别的结果，并引用原图。捕获和识别是否由不同的 Observer 负责，按谁形成观测来确定，见 [OBSERVER-6](../../core/model/observer.mdx#observer-6)。这个来源还没有截图入口或识别适配器，也没有登记 EntitySchema。

## 实体 [#entities]

| 实体 | 含义 | 身份 | 要保留的信息 |
| --- | --- | --- | --- |
| 图像材料 | 已取得的原始图像 | 按内容识别；可以被多次捕获或识别引用 | 字节表示；来源范围 |
| 图像捕获 | 一次捕获 | 每次捕获一个；像素相同也各自保留 | 来源和捕获范围；请求开始和完成的边界；图像材料 |
| OCR 结果 | 一次文字识别的输出 | 识别运行的身份；重新识别另存一份 | 图像材料；页、块、段落、词、字符；置信度和位置 |
| 图像检测结果 | 一次模型检测的输出 | 识别运行的身份；同一类别的多个框是不同的实例 | 图像材料；标签、框、置信度和模型版本 |

## 事实时间 [#fact-time]

捕获的请求和完成边界只描述捕获这个操作。识别结果的事实时间表达的是图像中的事实还是识别运行本身，由 EntitySchema 规定；处理完成的时间与原图的时间分开。
