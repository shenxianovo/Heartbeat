title: "Screen Capture"
description: "屏幕捕获、OCR 与图像检测"
---

区分捕获像素与解释图像：捕获记录取得的画面范围；OCR 和对象检测各自记录一次识别结果，并引用原图。尚无截图入口或识别适配器，也未登记 Schema。捕获主体与识别主体是否分开，按形成观测的责任确定。

## 实体

| 实体 | 含义 | 身份 | 需要保留的信息 |
| --- | --- | --- | --- |
| 图像材料 | 已取得的原始图像 | 内容身份；可被多次捕获或识别引用 | 字节表示；来源范围 |
| 图像捕获记录 | 一次捕获发生 | 每次捕获一条；相同像素不合并 | 来源与捕获范围；请求开始与完成边界；图像材料 |
| OCR 结果 | 一次文字识别的输出 | 识别运行身份；重跑另存 | 图像材料；页、块、段落、词、字符；置信度与几何 |
| 图像检测结果 | 一次模型检测的输出 | 识别运行身份；同类多个框是不同实例 | 图像材料；标签、框、置信度与模型版本 |

## 事实时间

捕获的请求与完成边界只描述捕获操作。识别结果的时间表达图像事实还是识别运行，由 Schema 规定；处理完成时间不作为原图时间。
