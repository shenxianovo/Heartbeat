前台状态、输入事件和设备状态分别维护 Observer 身份，可以运行在同一个程序中。

## Observers

| Observer | 记录的事实 |
| --- | --- |
| [Foreground State](../application-activity/index.mdx) | 当前前台应用与窗口标题，以及它们各自持续的时段 |
| [Input Events](../input-events/index.mdx) | 每次键盘或鼠标输入 |
| [Device State](../device-state/index.mdx) | 有证据的设备休眠、清醒与会话锁定等独立状态；具体实体见该页 |

## 记录维度

每类记录按自身证据形成与补全，不因另一维度的状态裁剪时间线。

例如，系统持续确认 Codex 在前台时，前台应用观测可以与会话锁定观测在时间上重叠。需要计算“未锁定时的前台时长”等结果时，再组合相应的记录。前台时长本身不表示用户活跃，本轮不定义“用户活跃”或无输入阈值。

读取失败、停止采集或读数间隔超过业务允许范围时，按各业务的证据边界结束记录；没有读数的空白不补成事实。
