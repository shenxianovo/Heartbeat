---

依据本地日志或回调，记录自己进入、离开和切换实例，以及来源提供的玩家在场。尚无采集入口，也未登记 Schema。

## 实体

| 实体 | 含义 | 身份 | 需要保留的信息 |
| --- | --- | --- | --- |
| 世界 | 在场记录涉及的世界 | 按来源世界标识 | 来源标识 |
| 实例 | 世界中的具体实例 | 同一世界的不同实例分开识别 | 所属世界 |
| 本地在场记录 | 本地玩家的一次加入、离开或切换 | 每个发生项一条；重连另起记录 | 世界、实例、会话或连接范围；事件证据与事件时间 |
| 玩家在场记录 | 来源在某实例内报告的玩家状态 | 实例内 `playerId` 只在该实例内有效 | 来源范围；玩家标识、角色与可见状态；来自初始化名单还是后续回调 |

## 事实时间

来源给出加入或离开时间时使用该时间。初始化名单的时间表示“此刻看见”，作为状态观测，不作为他人的到达时间。两次连接之间的空白不计入在线。
