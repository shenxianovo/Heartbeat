---
title: "Browser History"
description: "网页访问、历史条目与删除通知"
---

在一个浏览器 profile 范围内记录网页访问、历史条目和删除通知。每次访问有自己的身份，同一网址可以被访问多次。尚未接入，也未登记 Schema。

## 实体

| 实体 | 含义 | 身份 | 需要保留的信息 |
| --- | --- | --- | --- |
| 网页历史条目 | profile 内的 URL 级条目 | 来源条目标识与 profile 范围 | URL；同步来源 |
| 访问记录 | 一次网页访问 | 来源 `visitId` | 所属条目；`referringVisitId`；`transition`；`visitTime`；`isLocal` |
| 历史删除通知 | 浏览器报告的一次删除 | 通知身份 | 是否删除全部历史；URL 范围；删除时间 |

## 事实时间

访问时间是时间点，不形成停留时长。同步记录使用原访问时间。删除通知只覆盖来源列出的范围；来源没有删除时刻时为 `null`。
