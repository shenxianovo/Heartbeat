---
title: "Browser History"
description: "网页访问、历史条目与删除通知（草案）"
---

在一个浏览器 profile 的范围内，记下网页访问、历史条目和删除通知。每次访问有自己的身份，同一个网址可以被访问多次。这个来源还没有接入，也没有登记 EntitySchema。

## 实体 [#entities]

| 实体 | 含义 | 身份 | 要保留的信息 |
| --- | --- | --- | --- |
| 网页历史条目 | profile 中一个网址的条目 | 来源的条目标识，在 profile 范围内有效 | URL；同步来源 |
| 访问 | 一次网页访问 | 来源的 `visitId` | 所属条目；`referringVisitId`；`transition`；`visitTime`；`isLocal` |
| 历史删除通知 | 浏览器报告的一次删除 | 通知的身份 | 是否删除了全部历史；URL 范围；删除时间 |

## 事实时间 [#fact-time]

访问只记一个时间点。从其他设备同步来的访问，使用原来的访问时间。删除通知只覆盖来源列出的范围；来源没有给出删除时刻时为 `null`。
