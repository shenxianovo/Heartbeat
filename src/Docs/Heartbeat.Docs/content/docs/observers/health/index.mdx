title: "Health"
description: "步数与睡眠记录"
---

保存健康来源已有的步数和睡眠记录，不推导健康结论，也不跨来源汇总每日统计。步数与睡眠分别定义。来源尚未接入，也未登记 Schema。

## 实体

| 实体 | 含义 | 身份 | 需要保留的信息 |
| --- | --- | --- | --- |
| 步数记录 | 来源定义的一天、区间或一次累计读数 | 来源记录标识；来源修订时替换内容实体并沿用业务身份，需要保留旧值时按 [HISTORY-5](../../core/rules/history.mdx#history-5) 另存内容版本 | 计数含义；数量；当地日期或区间及其时区；计步器启动/重置范围与原始时钟 |
| 睡眠记录 | 来源报告的一次睡眠 | 来源记录标识；修订关联原记录 | 起止边界；来源状态与修订 |
| 睡眠阶段 | 睡眠记录中的一个阶段 | 按来源记录与顺序 | 所属睡眠记录；阶段类别；时间范围 |

## 事实时间

每日步数保留本地日期及其所属时区，旅行时不按导入地时区重新分日。睡眠使用来源时段，跨夏令时按实际偏移解释。阶段之间允许空档，未知阶段不补成清醒或深睡。
