title: "Health"
description: "步数与睡眠（草案）"
---

保存健康来源已有的步数和睡眠数据，按来源原样记下。健康结论和跨来源的每日汇总由读取方推断。步数和睡眠分别定义。这个来源还没有接入，也没有登记 EntitySchema。

## 实体 [#entities]

| 实体 | 含义 | 身份 | 要保留的信息 |
| --- | --- | --- | --- |
| 步数读数 | 来源定义的一天、一个区间或一次累计读数 | 来源的条目标识。来源修订数值时，形成同一实体的新版本，旧值留在旧版本中，见 [HISTORY-3](../../core/rules/history.mdx#history-3) | 计数的含义；数量；当地日期或区间及其时区；计步器启动或重置的范围；原始时钟 |
| 睡眠 | 来源报告的一次睡眠 | 来源的条目标识；修订关联到原来的睡眠 | 开始和结束边界；来源中的状态和修订 |
| 睡眠阶段 | 一次睡眠中的一个阶段 | 按来源的条目和顺序 | 所属的睡眠；阶段类别；时间范围 |

## 事实时间 [#fact-time]

每日步数保留当地日期和所属时区；旅行时，日期按来源的时区划分，与导入时所在的时区无关。睡眠使用来源给出的时段，跨夏令时的时段按实际偏移解释。阶段之间可以有空档，未知的阶段保持未知。
