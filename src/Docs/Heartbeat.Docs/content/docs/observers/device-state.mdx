设备状态 Observer 形成设备休眠和清醒状态的观测。设备状态、前台状态和输入事件 Observer 分别拥有实例身份。三个 Observer 可以运行在同一程序中。

数据字段与采集规则仍为草案。设备状态采集尚未实现。

## ObserverId

`ObserverId` 标识一个独立的设备状态采集器实例。同一实例多次采集、重启或升级时，采集器沿用原身份。另一台设备或独立实例使用自己的身份。

`ObserverId` 标识采集器实例，不作为设备实体 ID。具体身份生成、本地保存与设备关联方式尚未确定。

## EntitySchema

[设备休眠与清醒](./schemas/device-state.mdx)定义设备状态。草案用 `state` 区分 `awake` 与 `asleep`。

设备清醒、会话未锁定和近期存在输入是不同事实。锁屏的责任归属和“用户活跃”的推断规则尚未确定，不合并到当前设备状态定义中。

各平台遵循相同事实含义、字段和时间规则时，共用一份 EntitySchema。

## ITimed

设备状态使用时间段 Observation。起止时间表示已知的状态边界，不表示采集程序启动或提交的时间。

休眠和清醒边界的判定规则尚需确认。程序停止或崩溃后的采集空白处理规则也需确认。

如果没有状态证据，状态必须保持未知。采集器不得仅凭没有输入或读数生成休眠观测。

Observer、EntitySchema 和观测内容只实现 `IEntity`。模型时间规则见 [ITimed](../core/model/contracts/timed.mdx)，组件职责见 [ADR 0002](../adr/0002-observer-capabilities-and-platform-clients.mdx#桌面观测职责)。
