## 目录

桌面观测统一从 [Desktop](./desktop/index.mdx) 进入，下面展开前台状态、输入事件与设备状态。

| Observer | 观测内容 |
| --- | --- |
| [Foreground State](./application-activity/index.mdx) | 前台应用时段与窗口标题时段 |
| [Input Events](./input-events/index.mdx) | 逐条键鼠事件 |
| [Device State](./device-state/index.mdx) | 设备休眠与清醒时段 |
| [Browser History](./browser-history/index.mdx) | 网页访问与历史删除 |
| [Assistant Sessions](./assistant-sessions/index.mdx) | 助手会话、执行与工具调用 |
| [Screen Capture](./screen-capture/index.mdx) | 屏幕捕获、OCR 与图像检测 |
| [Health](./health/index.mdx) | 步数与睡眠 |
| [VRChat](./vrchat/index.mdx) | 实例加入、离开与玩家在场 |
| [Playback](./playback/index.mdx) | 媒体播放状态与进度 |
| [Audio](./audio/index.mdx) | 音频材料、片段与说话人 |

前台状态由独立程序 `src/Observers/Heartbeat.Observer.ForegroundState/` 运行。运行方式在该模块 README。

## 页面结构

文档按“分类 → Observer → 业务实体”组织：分类提供导航；Observer 主页面说明职责、实例身份、采集、事实时间和提交策略；实体子页集中定义记录粒度、身份、引用、时间、Schema 与示例。新接入按 [Integration Guide](./integration.mdx) 设计，按 [Document Template](./template/index.mdx) 编写。
