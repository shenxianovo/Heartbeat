本定义表达“设备处于休眠或清醒状态的时段”，由[设备状态 Observer](./index.mdx)形成观测。草案，尚未分配 SchemaId。

## 记录粒度

一条观测表达设备处于休眠或清醒状态的一段事实。何时开始、补全或结束同一条记录，取决于取得的状态边界证据；具体判定规则待定。

## 身份

状态内容的身份与复用规则待定；Observer 实例身份与设备身份分别定义，见 [Device State](./index.mdx#实例身份)。

## 引用

被观测设备的实体定义与引用字段待定。

## 事实时间

Observation 保存状态起止边界，已知时为 `[startAt, endAt)`，遵循 [Observation · 事实时间](../../core/model/observation.mdx#fact-time)。

## Schema

| 项目 | 值 |
| --- | --- |
| SchemaId | 待定 |
| 显示名称 | 设备休眠与清醒状态 |
| 说明 | 表达设备处于休眠或清醒状态的一段事实；Observation 保存已知状态边界。 |
| 资源名 | 待定 |

| 字段 | 类型 | 必填 | 可空 | 含义 |
| --- | --- | --- | --- | --- |
| `state` | `string` | 待定 | 待定 | `awake` 设备清醒；`asleep` 设备休眠 |

## 示例

业务实体提交结构如下：

```json
{
  "references": {},
  "properties": { "state": "asleep" }
}
```

设备引用尚未定义，示例只展示已列出的状态字段。

## 待定

- SchemaId、资源名与字段必填、可空约束。
- 状态内容身份、设备引用与内容复用规则。
- 用系统休眠或唤醒证据确定边界的规则。
- 启动时取得状态的方式。
- 停止或崩溃后的采集空白。
