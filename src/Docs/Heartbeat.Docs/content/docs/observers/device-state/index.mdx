设备状态 Observer 记下有证据的设备休眠、清醒和会话锁定。程序实例的身份和被观测设备的身份是两回事，分别定义。

<ObserverStructure node="DEVICE_STATE" />

## 实体 [#entities]

| 实体 | 资源名 | 说明 |
| --- | --- | --- |
| [Sleep State](./sleep-state.mdx) | 待定 | 有证据的休眠或清醒状态 |

设备清醒和会话锁定分别建模。设备实体和会话锁定实体尚未定义。

设备状态是一条独立的时间线：它只记下设备的状态，其他 Observer 的时段不因它而切开，见 [Desktop · 各自的时间线](../desktop/index.mdx#timelines)。

## 程序实例 [#instance]

程序实例重启或升级后沿用原来的身份。身份怎样生成、保存在哪里，尚未确定。

## 采集 [#collection]

只有取得状态的证据时才形成观测；没有输入、没有前台数据，都不能当作休眠的证据。休眠和唤醒的证据从哪里读、启动时怎样取得初始状态、停止或崩溃后的空白怎样处理，尚未确定。

## 事实时间 [#fact-time]

Observation 的边界取自已知的状态边界，见 [Sleep State · 事实时间](./sleep-state.mdx#fact-time)。

## 提交 [#submission]

接入时登记程序实例和已定义的 EntitySchema，之后业务代码形成观测内容和 Observation，交给所在平台的 SDK，提交规则见 [Submission](../submission/index.mdx)。

## 待定 [#open]

- 程序实例身份的生成和本地保存；设备实体的身份依据、字段，以及它与状态内容的关联。
- 休眠与清醒边界的判定；启动时取得初始状态；停止或崩溃后的空白。
- 会话锁定的实体、EntitySchema、状态边界和采集方式。
- 提交策略、更新和结束条件。
