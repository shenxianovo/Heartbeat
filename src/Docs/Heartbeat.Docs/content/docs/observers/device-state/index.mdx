设备状态 Observer 记录有证据的设备休眠、清醒与会话锁定状态。`ObserverId` 标识采集实例，与被观测设备的身份分开。

## Entity 与 Schema

| Entity 与 Schema | 资源名 | 说明 |
| --- | --- | --- |
| [Sleep State](./sleep-state.mdx) | 待定 | 有证据的休眠或清醒状态 |

设备实体与会话锁定实体尚未定义，不单独建立实体子页。设备清醒与会话锁定分别建模；记录设备状态不负责推断用户是否活跃，也不触发其他 Observer 裁剪记录，见 [Desktop · 记录维度](../desktop/index.mdx#记录维度)。

## 实例身份

同一实例重启或升级时沿用身份。身份生成与本地保存方式待定。

## 采集

只在取得状态证据时形成观测，不根据没有输入或没有前台数据推断设备休眠。休眠与唤醒证据的读取方式、启动时取得初始状态，以及停止或崩溃后的空白处理待定。

## 事实时间

Observation 的边界取自已知的状态边界。

## 接入与提交策略

接入时登记 Observer 身份与已定义的业务 Schema，再由业务形成内容和 Observation，交给所用平台的提交 SDK。Sleep State 的 Schema 元信息及设备关联尚待确定。

提交遵循[共同约定](../submission/index.mdx)。

## 待定

- 实例身份的生成与本地保存；设备实体的身份依据、字段及与状态内容的关联。

- 会话锁定的实体、Schema、状态边界与采集方式。
- 提交策略、更新与结束条件。
