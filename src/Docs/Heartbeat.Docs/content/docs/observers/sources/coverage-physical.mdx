## C01

**GPS 定位及误差**

原场景验收点：经纬度之外保留误差半径；不能把估计写成精确位置。

- 接入状态：仅相关适配器
- CLI 来源：`gpx-xml`；[格式与运行规则](./calendar-track.mdx)
- 命名断言：`PhysicalCalendarSourceTests.GpxPreservesBackwardClockAndRepeatedIdenticalPoints`
- 测试文件：`tests/Heartbeat.Model.Tests/PhysicalCalendarSourceTests.cs`
- 剩余缺口：仅相关 GPX 点位/fix/DOP 适配器；Android 设备、boot elapsed time 与米制 accuracy 未接入，DOP 不能替代误差半径。
- 模型输入：`tests/Heartbeat.Model.Tests/Fixtures/physical.json` 中的 `C01`
- 来源规范：[来源1](https://developer.android.com/reference/android/location/Location)
