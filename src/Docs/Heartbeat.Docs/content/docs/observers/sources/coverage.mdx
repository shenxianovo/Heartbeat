这 100 项沿用第一阶段的 A01–D25 编号。每项标出真正的来源入口、原生测试和剩余缺口；**不是 100 个已完成连接器**。纯模型表达与 HTTP 类型读回仍见[模型压力测试](../../testing/model-generality/index.mdx)，完整原始 fixture 可[下载](/model-stress/scenarios.json)。

机器可核对的权威接入清单位于 `src/Observers/Heartbeat.Observer.Sources/scenario-coverage.json`。测试名表示对应断言已写入仓库；当次执行结果与平台范围见[来源验证](./verification.mdx)。不能用解析器存在或项目总通过数替代逐项语义覆盖。

## 状态怎么读

| 状态 | 含义 |
| --- | --- |
| 原生核心断言 | 对原生格式写了该场景核心语义断言；仍有页面内列出的范围，不代表完整生产服务 |
| 原生实现·部分 | 有可运行来源路径和直接测试，只覆盖原场景的一部分 |
| 替代格式·部分 | 如 ICS 对 Google Calendar、GPX 对 Android Location；不冒充原提供商接入 |
| 仅相关适配器 | 同家族有解析器，但原场景关键语义未实现或没有直接断言 |
| 仅模型样本 | 保留原来的模型/Schema fixture，尚无本场景原生来源实现 |
| 既有采集器·平台未实跑 | 已有 macOS 采集器和逻辑测试；本轮 Linux 未实跑 macOS 来源 |
