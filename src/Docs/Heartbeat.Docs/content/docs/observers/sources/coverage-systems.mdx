- 接入状态：原生核心断言
- CLI 来源：`git`；[格式与运行规则](./local.mdx)
- 命名断言：`LocalSourceTests.GitReadsNativeCommitTimesOrderedParentsAndRefKinds`
- 测试文件：`tests/Heartbeat.Model.Tests/LocalSourceTests.cs`
- 剩余缺口：实际临时 Git 仓库断言作者/提交者各自时间；只捕获 HEAD，不遍历全部提交。
- 模型输入：`tests/Heartbeat.Model.Tests/Fixtures/systems.json` 中的 `B01`
