Heartbeat 保存一个人经历了什么。

人会换设备、换应用、换 AI 助手，留在这些软件里的信息也随之散落。Heartbeat 把它们收拢成一份属于用户的记录：用过的应用、键鼠活动、浏览历史、健康数据，以及模型的推断和用户的确认、否定。软件换了，记录还在。这样定位的理由见 [ADR · 定位与边界](../adr/positioning.mdx)。

## 核心想法 [#ideas]

- 每一份观测说明四件事：谁负责、说了什么、依据什么、事实在什么时间成立。
- 数据改动时形成新版本，旧版本保留。引用指向确定的版本，所以追溯时看到的是当时的内容。
- 每种数据的字段和含义由 EntitySchema 声明，和数据保存在一起，换了软件也能读懂。
- 后端只检查结构。一件事实怎样判断，由各来源的业务规则决定。
