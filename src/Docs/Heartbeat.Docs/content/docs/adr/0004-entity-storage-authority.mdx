---
title: "0004 统一索引定位实体的权威存储"
---

实体索引和内容保存在 PostgreSQL。每个实体只能有一份权威内容。统一索引保存实体标识和内容所在的表名。后端先查询索引，再读取内容。

业务实体由 EntitySchema 声明模型，每个业务 SchemaId 对应一张业务表。后端根据声明创建表、校验和还原实体，统一索引指向对应业务表。具体职责见 [ADR 0011](./0011-entity-schema-driven-storage.mdx)。

保存单个实体时，后端在同一事务中登记索引、检查模型类别并写入内容。索引和内容必须同时写入成功，或同时回滚。同一 ID 的并发写入通过索引行锁依次执行。

内容表通过外键引用统一索引。如果删除索引行，数据库级联删除同 ID 的内容。Observation 和业务实体的引用不建立目标外键，允许先保存引用方、再保存被引用实体。

后端使用 .NET 10、Entity Framework Core（EF Core）和 Npgsql。EF Core 管理映射和迁移，Npgsql 访问 PostgreSQL。重写期间直接修改 Initial migration 和模型快照。

表结构、数据库类型、版本和约束见 [Heartbeat Storage](../storage/index.mdx)。
