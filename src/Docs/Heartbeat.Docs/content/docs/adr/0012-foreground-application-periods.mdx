## 身份职责

前台状态采集器负责识别本机应用。macOS 实现用包标识和可执行文件路径的原始值匹配安装。名称不参与匹配；路径或包标识变化时新建身份。原地升级和无法辨别的同路径重装沿用身份。

本机应用登记文件是原生线索到 EntityId 映射的权威来源。文件与 Observer 身份文件分离，同一设备上的多个实例共享应用身份。另一台设备使用自己的登记文件。当前不增加 Device 实体或跨平台应用归一化层。

缺少路径时，只在采集器本次运行中按进程号、启动时间和包标识复用身份。这些进程线索不写入业务实体。进程线索不足时，每次新建身份。此规则减少错误合并；多个身份是否属于同一软件，由业务关联处理。

## 时段职责

采集器负责将连续读数合并为时段。应用激活事件触发读取，每 1 秒定时确认作为兜底；超过兜底间隔 3 倍即视为中断。名称或时区变化会分段，历史内容不被覆盖。

macOS 使用包含休眠和不含休眠的两种计时发现休眠。计时差或墙上时间增量偏差超过 100 毫秒时断开；墙上时间倒退或重复也断开。Apple 的 [Mach 时间接口](https://github.com/apple/darwin-xnu/blob/main/osfmk/mach/mach_time.h)说明两种计时的休眠差别。

休眠通知立即结束当前时段，唤醒后重新读取。通知遗漏时，计时差检查仍可断开时段。

## 本地记录与发送职责

SQLite 是当前时段和待发送内容的本地权威来源。当前时段只在本地更新，结束后才进入 Outbox。关闭旧时段、入队和保存新时段使用同一本地事务。Outbox 保留六个实体的完整提交内容，发送期间不重新生成 ID、字段或时间。

重启时，采集器按最后一次持久化的确认边界结束遗留时段。网络发送独立于采集。发送方查询实体，缺少时提交，后续查询全部内容一致后删除 Outbox 记录。已有内容不一致或请求失败时保留记录。协议使用现有 PUT 与 GET，不增加确认接口。

已结束时段保持不变，因此读回匹配能够判断这份本地记录是否已保存。后端保存这些实体后提供统一读取；进行中的时段由本地管理。

字段、示例和时间规则见[本机应用](../observers/entities/local-application.mdx)、[前台应用时段](../observers/schemas/foreground-application-interval.mdx)与[前台状态](../observers/foreground-state.mdx)。
