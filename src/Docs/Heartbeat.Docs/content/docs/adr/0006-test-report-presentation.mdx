---
title: "0006 TUnit 报告的来源与展示职责"
---

测试执行项目负责运行测试并生成 `TestResults/*.tunit-report.json`。这份原始 JSON 是测试结果的权威来源，测试报告不进入实体数据库。

文档站在 Testing 分区读取最近更新的集成测试报告，通过 `fumadocs-test-reports` 展示。包负责校验原生 TUnit 字段与报告交互；文档站负责文件读取、页面路由和语言选择。报告数据保持 TUnit 原生结构。

报告页每次刷新读取文件。没有报告时显示尚未生成，查看报告不运行测试。Docker 将宿主的 `TestResults` 目录只读挂载到文档站。

报告与镜像分开保存，使报告更新无须重建文档站。具体路径和操作说明见文档站 README。
