---
title: "0008 开发入口与验证职责"
---

Compose 是本地服务配置、依赖关系和启动顺序的唯一来源。`Heartbeat.Dev` 为人和 Agent 提供统一入口，直接调用仓库的 Compose 文件，选择全部或单独的 API、文档站、数据库栈，并检查实际入口就绪。开发模式使用基础配置与开发覆盖，生产构建通过 `--release` 在本地验证。NGINX 独立启动，允许只运行一个应用栈。

开发工具组织当前项目的构建、测试、质量扫描和证据保存。复杂度、重复代码、疑似未使用代码及依赖是供审查的观察结果；必要复杂度可以保留，是否简化取决于行为与维护成本。构建、测试失败或扫描未完成使验证失败。扫描覆盖业务实现、文档站和开发工具，测试重复与代码行数单独统计。

每次验证的执行清单、结果与日志由开发工具保存在独立运行目录，成功、失败和取消均留证。TUnit 原始报告继续作为测试结果的权威来源，由文档站展示，职责见 [ADR 0006](./0006-test-report-presentation.mdx)。操作说明维护在 `tools/Heartbeat.Dev/README.md`。
