---
title: "0001 文档站源文件作为唯一权威位置"
---

Heartbeat 的长期文档保存在 `src/Docs/Heartbeat.Docs/content/docs/`。Fumadocs 根据这些源文件生成文档站。

模型、术语和设计决策都在源文件中修改。人和 Agent 使用同一份正文。

模型正文只记录用户已确认的结构与语义。Agent 根据已确认内容起草和整理文档。

改变模型语义前，Agent 必须逐项得到用户确认。

根目录 `README.md` 与 `AGENTS.md` 提供入口和维护规则。`grill-with-docs` 使用仓库规定的术语页与设计决策记录（ADR）路径。

文档站的页面、资源和搜索接口统一使用 `/docs` 路径前缀。应用前端使用根路径 `/`。
