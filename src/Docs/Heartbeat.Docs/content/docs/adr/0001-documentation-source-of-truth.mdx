---
title: "0001 文档与 API 契约的权威来源"
---

长期文档统一保存在 `src/Docs/Heartbeat.Docs/content/docs/`。人和 Agent 使用同一份模型、术语和设计决策，避免多份文档产生冲突。模型正文只记录用户已确认的结构与语义。

API 请求与响应结构以 `Heartbeat.Api` 的端点、请求类型和契约声明为准。后端构建生成 `content/docs/api/openapi.json`，文档站从该文件生成接口页。修改接口时必须修改后端声明并重新生成文件，不得直接编辑生成文件。

`openapi.json` 随后端代码提交，供审查契约变化。文档站读取仓库中的生成文件，因此可以独立构建和运行。

HTTP 入口见 [ADR 0006](./0006-unified-http-entry.mdx)。文档站操作说明见模块 README，Agent 的维护规则见仓库根目录的 `AGENTS.md`。
