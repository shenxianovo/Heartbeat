---
title: "0001 文档与 API 契约的权威来源"
---

长期文档统一保存在 `src/Docs/Heartbeat.Docs/content/docs/`。人和 Agent 共用模型文档、术语表和设计决策。模型正文只记录用户已确认的结构与语义。

API 使用 OpenAPI First：先确定接口契约，再编写实现。请求与响应结构的权威来源是 `content/docs/api/openapi.json`。维护者直接修改该文件，文档站读取该文件展示接口。后端与客户端按契约手写实现，测试核对实际请求与响应。Core 定义领域模型。

维护者将用户在讨论中确认的结果写入对应接口。后端、客户端、测试和接口说明文档按契约同步。代码和其他文档不得反向修改接口契约。后端构建不生成或覆盖契约文件。

接口文档只描述确定的结构与行为，不记录实现进度。接口概览链接到契约，不重复维护完整请求或响应示例。

`openapi.json` 随代码提交，供审查契约变化。文档站可以独立构建和运行。客户端实现与契约一起维护，不接入客户端代码生成器。

HTTP 入口见 [ADR 0006](./0006-unified-http-entry.mdx)。文档站操作说明见模块 README，Agent 的维护规则见仓库根目录的 `AGENTS.md`。
