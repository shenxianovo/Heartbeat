## 目标

用最少的实体记录以下信息：

- 形成观测的主体。
- 观测引用的内容。
- 解释观测的实体定义。
- 被观测事实的时间。

业务定义数据结构、记录粒度和历史保留方式。

`IEntity` 提供统一的[实体引用枚举契约](./model/contracts/entity.mdx#约定)。普通引用参与实体关系图。业务定义关系含义，以及是否需要独立的业务实体。

## 代码位置

核心模型位于 `src/Core/Heartbeat.Core/`，命名空间为 `Heartbeat.Core`。Core 定义实体、基础能力接口和模型规则。Core 不依赖 ASP.NET Core、EF Core 或后端项目。

后端项目的职责与依赖见 [ADR 0005](../adr/0005-backend-project-organization.mdx)。
