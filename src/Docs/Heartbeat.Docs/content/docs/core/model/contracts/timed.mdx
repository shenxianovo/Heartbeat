## 含义

`ITimed` 通过 `StartAt` 和 `EndAt` 表达已知的时间边界。实现 `ITimed` 的类型定义时间边界的含义。

## 定义

```csharp
public interface ITimed
{
    DateTimeOffset? StartAt { get; }
    DateTimeOffset? EndAt { get; }
}
```

## 边界语义

| `StartAt` | `EndAt` | 含义 |
| --- | --- | --- |
| `null` | `null` | 起止时间均未知 |
| `t` | `t` | 时间点 |
| `t1` | `t2`，且 `t1 < t2` | 左闭右开区间 `[t1, t2)` |
| `t1` | `t2`，且 `t1 > t2` | 无效 |
| `t` | `null` | 开始已知，结束未知 |
| `null` | `t` | 开始未知，结束已知 |

`null` 只表示时间边界未知。状态由业务数据表达。

## 时间精度

`DateTimeOffset` 的时间粒度为 100 ns。系统使用微秒精度存储和读取时间。

如果来源时间的粒度小于 100 ns，业务定义转换时的舍入方式。

时间存储见 [Heartbeat Storage](../../../storage/index.mdx#时间存储)。传输与展示约定见 [Heartbeat API](../../../api/index.mdx#时间表示与职责)。

## 各类型的时间含义

| 实现类型 | 时间含义 |
| --- | --- |
| [Observation](../observations/observation.mdx) | 被观测事实的起止时间 |
| 业务实体 | 由具体业务定义时间含义 |
