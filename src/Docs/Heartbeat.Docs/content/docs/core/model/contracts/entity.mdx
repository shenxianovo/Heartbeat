## 含义

需要独立识别的事物实现 `IEntity`，通过 `Id` 提供稳定标识。

## 定义

```csharp
public interface IEntity
{
    EntityId Id { get; }
}
```

| 属性 | 类型 | 含义 |
| --- | --- | --- |
| `Id` | [EntityId](#entityid) | 当前实体的标识 |

## 约定

观测、观测主体、观测定义、具体数据和独立关系都实现 `IEntity`。

需要表达时间边界的类型实现 [ITimed](./timed.mdx)。

## 创建、存储与读取

采集程序创建实体。创建新实体时，采集程序调用 `EntityId.New()`。识别出已有实体时，采集程序沿用原 `EntityId`。

实体读写协议见 [Heartbeat API](../../../api/index.mdx)。统一索引、存储表和存储转换规则见 [Heartbeat Storage](../../../storage/index.mdx)。

## EntityId

`EntityId` 封装一个 `Guid`，用作实体标识。`New()` 创建 UUIDv7 标识。UUIDv7 是 UUID（通用唯一标识符）的第 7 版格式。

```csharp
public readonly record struct EntityId(Guid Value)
{
    public static EntityId New() => new(Guid.CreateVersion7());
}
```

引用其他实体时，使用 `EntityId`。

UUIDv7 中的时间表示标识的生成时间。事实时间由 [Observation](../observations/observation.mdx) 表达。
