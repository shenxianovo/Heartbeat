## 含义

`Relation` 是独立关系实体的抽象类。具体关系类型定义两端的方向、含义和自身属性。

## 定义

`+` 表示接口契约之外的属性。

```csharp
public abstract class Relation : IEntity, ITimed
{
    public required EntityId Id { get; init; }
    public required EntityId FromId { get; init; } // [!code ++]
    public required EntityId ToId { get; init; } // [!code ++]
    public DateTimeOffset? StartAt { get; init; }
    public DateTimeOffset? EndAt { get; init; }
}
```

| 属性 | 含义 |
| --- | --- |
| `Id` | 关系自身的实体标识 |
| `FromId`、`ToId` | 引用关系的两端实体，方向由具体关系定义 |
| `StartAt`、`EndAt` | 关系自身的时间范围，遵循 [ITimed](../contracts/timed.mdx) |

## 使用条件

普通引用优先使用具体类型中的 `EntityId` 字段。

如果关系需要独立身份、时间、属性或生命周期，则定义具体 `Relation` 子类。

关系时间表示关系自身的时间范围。两端实体的事实时间由各自的观测表达。

## 示例：Git 父提交

一个 Git 提交可以有多个父提交。普通引用可以使用多个父提交标识。

如果需要独立关系实体，可以为每个父提交创建一条具体关系。
