Web 控制台是 Orisumi 的完整读取界面，目前只在本机使用。首页“现在”显示各 Observer 正在写入什么、今天记下了什么；从任何一个 Observer 或版本出发，可以进入实体页，沿引用逐层追溯。

控制台是读取方：它读取所有 Observer 的数据，也可以删除实体，见 [ADR · 删除](../adr/deletion.mdx)。数据由 Observer 通过 SDK 写入。设备端客户端只展示今天的数据，更早的日期和追溯都在这里查看。

| 页面 | 内容 |
| --- | --- |
| 现在 | 今天各 Observer 的写入和 Observation，有心电、气泡、行和表盘四种视图 |
| 实体 | 一个实体的内容、引用链、版本和被引用 |
| EntitySchema | 已登记的 EntitySchema |

顶栏的输入框接受 EntityId 和 VersionId：先按 EntityId 读取，读不到再按 VersionId 读取。主题有跟随系统、浅色和深色三档，彩色只用来区分 Observer 的类别。

## 现在 [#now]

“现在”用四种视图展示同一份数据。选中一个 Observer 后，切换视图时它保持选中，其余的变淡。

| 视图 | 显示什么 | 时间 |
| --- | --- | --- |
| 心电 | 最近 20 秒的写入，指针从左向右扫；左上角是最近 60 秒的写入次数 | 保存时间 |
| 气泡 | 每个 Observer 一个气泡，面积随 10 分钟内的写入次数变化，同类别聚在一起 | 保存时间 |
| 行 | 每个活跃的 Observer 一行，最近 10 分钟的每次写入是一条竖线；安静的折叠成一行 | 保存时间 |
| 表盘 | 今天按 24 小时展开，每个 Observer 一圈，每份 Observation 一段弧；超过 24 圈时，Observation 少的合并成“其他” | 事实时间 |

一份 Observation 新出现或当前版本变了，算一次写入，画在它的保存时间上。控制台靠轮询发现写入，所以写入在发生约 2 秒后出现，同一份 Observation 在一个轮询间隔内的多次更新算一次；事实时间远离今天的补发不在“现在”出现。最近 60 秒内有写入的 Observer 算活跃。

Observer 的名称取它的 Schema 版本的 `displayName`，同名的加 EntityId 末 4 位。系统开启“减少动态效果”时，视图不播放动画。
