用户通过客户端使用 Orisumi。[Web 控制台](./web.mdx)在浏览器中读取和追溯全部记录；设备端客户端常驻在一台设备上，运行这台设备上的 Observer，并展示它们今天记下了什么。两者都通过 [API](../api/index.mdx) 访问后端。

客户端只托管 Observer，陈述由形成它的 Observer 负责，见 [OBSERVER-6](../core/model/observer.mdx#observer-6)。所以 Observation 的 Observer 仍是各个程序实例，记录中不出现客户端。这样分工的理由见 [ADR · 设备端客户端](../adr/device-client.mdx)。

## 平台 [#platforms]

| 客户端 | 类型 | 状态 |
| --- | --- | --- |
| [Web](./web.mdx) | 浏览器 | 已实现 |
| [macOS](./macos.mdx) | 设备端 | 已托管前台状态 Observer；安装、更新和故障恢复尚未实现 |
| Windows | 设备端 | 规划中 |
| Android | 设备端 | 规划中 |

## 设备端客户端 [#device]

设备端客户端托管本机的 Observer：安装、更新和卸载，启用和停用，故障后重启，显示运行和发送状态，管理设置和登录时启动。

例如用户在 macOS 上装好客户端，附带的前台状态 Observer 随即开始记录 VS Code 在前台的时段。用户晚上停用它，当前时段结束于最后一次确认，还没发送的时段继续上传；第二天再启用，它以原来的身份接着记录，停用期间是空白。

### 安装与卸载 [#install]

客户端从官方列表安装 Observer，新的 Observer 不用更新客户端就能安装。随客户端附带的 Observer 在安装客户端时一并安装，之后和其他 Observer 一样管理。

Observer 安装后直接开始采集。

卸载移除 Observer 的程序，保留程序实例的身份、设置和待发送的数据；后端已保存的记录不受影响。重新安装后，Observer 沿用原来的身份和设置，并直接开始采集。

### 启用与停用 [#enable]

每个 Observer 单独启用和停用，互不影响。

停用的 Observer 停止采集，程序保留。当前进行中的事实按这个 Observer 停止采集时的规则结束，例如前台时段结束于最后一次确认，见 [Foreground State · 采集](../observers/foreground-state/index.mdx#collection)。停用期间没有读数，记录中是空白。

再次启用时，Observer 沿用原来的身份和设置。

### 更新 [#updates]

Observer 有新版本时，客户端提示用户，用户确认后才安装。更新保留身份和设置：更新前在采集的 Observer，更新后继续采集；停用的保持停用。

### 故障恢复 [#recovery]

Observer 崩溃后，客户端自动重启它。连续失败后，客户端停止重启，显示错误，并提供重试的入口。客户端只重启用户启用的 Observer。

一个 Observer 的故障不影响其他 Observer，也不影响发送。

### 发送 [#sending]

SDK 的发送随客户端运行，见 [Submission · 由客户端托管](../observers/submission/index.mdx#hosting)。Observer 停用、崩溃或卸载后，它已经交给 SDK 的数据继续发送。

客户端按 Observer 显示待发送的数量和被拒绝的原因，见 [Submission · 发送状态](../observers/submission/index.mdx#status)。

### 运行与退出 [#lifecycle]

桌面客户端关闭窗口后，继续在菜单栏或系统托盘中运行，采集和发送照常进行。Android 客户端怎样在后台运行，尚未确定。

退出客户端时，所有 Observer 停止采集，发送也停止，待发送的数据留在本地。下次启动时，客户端运行退出前启用的 Observer，并继续发送。

### 今天的数据 [#today]

客户端展示每个 Observer 的运行和发送状态，以及今天的统计和最近的数据，包括还没发送的部分。今天的数据从 API 读取，再补上本地还没发送的部分。

Observer 可以提供自己的视图，例如前台状态 Observer 的今日时间线，见 [macOS · 今天的前台应用](./macos.mdx#today)。没有专用视图的 Observer，客户端显示它的状态和最近的数据。

更早的日期和追溯在 Web 控制台中查看，客户端提供入口。

## 待定 [#open]

- 官方列表和 Observer 的安装包：分发的位置；包的标识、版本、支持的平台和兼容的客户端版本；下载的校验；安装失败后保留什么。
- 发送与各语言 SDK：各语言的 SDK 怎样接入客户端中的发送；程序实例把数据交给发送的边界；身份和待发送的数据由谁读写；单独运行和由客户端托管时怎样共用本地数据。
- 运行协议：启用、停用和正常结束怎样完成；运行状态怎样报告；重启的次数、间隔和失败计数何时清零；更新失败后怎样恢复。
- 专用视图：Observer 怎样提供视图；客户端怎样承载视图、向它提供数据；视图出错时怎样处理。
- 今天的数据：本地和后端的数据怎样合并，发送完成后不重复显示；最近的数据显示多少、何时刷新。
- Observer 停用或卸载期间出现被拒绝的版本时，怎样处理，见 [Submission · 被拒绝的版本](../observers/submission/index.mdx#rejections)。
- 系统权限的引导。
- Android 上 Observer 怎样在后台运行、怎样与客户端通信。
