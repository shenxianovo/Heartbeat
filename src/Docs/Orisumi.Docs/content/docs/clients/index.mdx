用户通过客户端使用 Orisumi。[Web 控制台](./web.mdx)在浏览器中读取和追溯全部记录；[设备端客户端](./device.mdx)常驻在一台设备上，运行这台设备上的 Observer，并展示它们最近记下了什么。两者都通过 [API](../api/index.mdx) 访问后端，也都能[管理](./management.mdx)任何一台设备和服务器上的 Observer。

客户端只托管 Observer，陈述由形成它的 Observer 负责，见 [OBSERVER-6](../core/model/observer.mdx#observer-6)。所以 Observation 的 Observer 仍是各个程序实例，记录中不出现客户端。这样分工的理由见 [ADR · 设备端客户端](../adr/device-client.mdx)。

## 平台 [#platforms]

| 客户端 | 类型 | 状态 |
| --- | --- | --- |
| [Web](./web.mdx) | 浏览器 | 已实现 |
| [macOS](./macos.mdx) | 设备端 | 已实现：经 Runtime 托管，附带前台状态 Observer；官方目录尚未托管 |
| Windows | 设备端 | 规划中 |
| Android | 设备端 | 规划中 |
