## 菜单栏 [#menu-bar]

客户端平时只在菜单栏显示图标：有 Observer 在采集时是彩色，否则变灰；Runtime 或某个 Observer 故障、发送被暂停时，图标上有红点。

菜单显示 Runtime 的状态、每个已安装的 Observer、等待发送的总数，以及发送被暂停的 Observer：

| 菜单项 | 作用 |
| --- | --- |
| Observer 名称 | 勾选即启用，再点一次停用。停用时进行中的事实按它的规则结束，待发送的版本继续发送 |
| 重新启动 Runtime | Runtime 连续意外退出、客户端停止重启后出现 |
| 打开 Orisumi | 打开窗口 |
| 打开 Web 控制台 | 用浏览器打开设置中的 Web 控制台地址 |
| 设置… | 打开设置窗口 |
| 退出 Orisumi | Runtime 先停止所有 Observer，再停止发送，然后客户端退出 |

窗口或设置可见时，客户端每 2 秒刷新一次数据；都关闭后，每 15 秒读取一次 Observer 的状态，用于菜单栏图标。

## 窗口 [#window]

窗口展示 Observer 的数据。侧栏为每个已安装的 Observer 列一个视图：有专用视图的按记录的内容命名，例如前台状态 Observer 的视图叫“前台应用”；没有专用视图的用 Observer 的名称，打开后是它[最近的数据](#recent)。Observer 停用或出了问题时，侧栏中它的视图旁有标记。

视图顶部在需要时显示一条横幅：

- 视图的 Observer 已停用：说明它不在记录，并提供启用。
- 视图的 Observer 故障、发送被暂停或发送出错：说明原因，并提供重试或打开设置。
- Runtime 故障：所有视图都显示，并提供重新启动 Runtime。

窗口打开时客户端出现在 Dock 中，关闭后只留在菜单栏。工具栏的“Web 控制台”打开 Web 控制台，其他日期和追溯在那里看。

## 设置 [#settings]

设置是单独的窗口，从窗口侧栏底部、菜单或 ⌘, 打开，分三组：

| 分组 | 内容 |
| --- | --- |
| 通用 | 外观、登录时启动 |
| Observer | 已安装的 Observer、已卸载但还有待发送数据的 Observer，以及添加 Observer |
| 高级 | API 地址、Web 控制台地址、本机数据目录 |

Observer 组的每一项显示名称、版本、进程状态、发送状态和启用开关，错误、被拒绝的版本和采集提示显示在这一项下面。可以对它做的操作是更新、重试、卸载和重新安装。

“添加 Observer”列出官方目录和附带的安装包中本机可以安装的 Observer，每一项说明它记录什么，并只给一个操作：安装、重新安装、更新到新版本，或在窗口中打开已安装的那一个。不适用于这台 Mac 的排在最后。

外观可以选跟随系统、浅色或深色，只改变 Orisumi 自己的窗口、弹窗和菜单，默认跟随系统。

## 今天的前台应用 [#today]

前台状态 Observer 的专用视图。客户端用 `read` 读取今天的前台应用时段，再用 `versions` 读取时段的内容、它引用的本机应用版本和应用的标识。

视图顶部是今天的前台总时长。下面左边是 24 个小时的柱状图，每小时的前台时长按应用堆叠；右边是应用列表，列出每个应用的时长和占今天总时长的比例。选中一个应用后，图表突出它，下方只列出它的时段；不选时列出全部时段，按时间倒序。

- 只有草稿状态的时段显示为进行中。
- 时长按已确认的结束边界计算，不随客户端的时钟延长。
- 被引用的内容和本机应用每次刷新都用 `versions` 读取。后端已删除的不再显示；暂时读不到时沿用上一次的内容，并标明可能不完整。
- `read` 或 `versions` 报告后端不可用时，视图标明“可能不完整”。
