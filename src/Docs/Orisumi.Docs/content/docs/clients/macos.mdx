## Observer 的管理 [#management]

窗口的侧栏列出已登记的 Observer，每一项显示名称和进程状态。选中一个 Observer，右侧显示它的启用开关、版本、进程和发送状态、错误和采集提示，以及更新、重试和卸载的操作。已卸载但仍有待发送数据的 Observer 列在侧栏的“已卸载”下。

“添加 Observer”列出官方目录和附带的安装包中本机可以安装的 Observer。

## 最近的数据 [#recent]

没有专用视图的 Observer，详情中列出最近 7 天的 Observation，最多 50 份：事实时间、本机状态（进行中、待发送、已保存、被拒绝）和观测内容的 JSON。数据经 Runtime 的 `read` 读取，见 [Runtime · 读取](./runtime.mdx#reading)。

## 今天的前台应用 [#today]

前台状态 Observer 的专用视图。客户端用 `read` 读取今天的前台应用时段，再用 `versions` 读取时段的内容、它引用的本机应用版本和应用的标识。这些时段画成按小时的时间线，按应用汇总，并按时间列出。

- 只有草稿状态的时段显示为进行中。
- 时长按已确认的结束边界计算，不随客户端的时钟延长。
- 被引用的内容和本机应用每次刷新都用 `versions` 读取。后端已删除的不再显示；暂时读不到时沿用上一次的内容，并标明可能不完整。
- `read` 或 `versions` 报告后端不可用时，视图标明“可能不完整”。
