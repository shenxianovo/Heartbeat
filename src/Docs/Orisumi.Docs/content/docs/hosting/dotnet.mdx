title: ".NET"
description: ".NET 编写的 Observer 怎样通过 SDK 连接 Runtime"
---

.NET 编写的 Observer 引用 `src/Observers/Orisumi.Observer.Sdk/` 连接 [Runtime](./runtime.mdx)。前台状态 Observer 用的就是它，见 [Foreground State · 提交](../observers/foreground-state/index.mdx#submission)。

SDK 读取 `init`，把业务操作编码成管道中的请求，等待 Runtime 的结果，再把提交的结果、错误和后端的读取结果交给业务代码，见 [Protocol · Observer 管道](./protocol.mdx#observer-pipe)。业务代码交来二进制内容的字节和媒体类型，SDK 计算摘要和大小，写成 `binary` 字段的描述，并把字节放进同一个批次。SDK 只处理管道、JSON 和请求的对应，形成版本和提交由 Runtime 完成，业务代码按 [Submission](./submission.mdx) 的约定使用它。

测试可以通过 `RuntimeObserverSession` 直接调用 Runtime 处理 Observer 的请求，不经过管道。
