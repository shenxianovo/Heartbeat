人是一个[事物](../../core/model/thing.mdx)，这种类型由[后端内置](../../core/rules/understanding.mdx#thing-types)。用户本人是其中一个，用户作为 Observer 形成的每份 Observation，都通过 `observerId` 引用它。其他人由模型从证据中认出，例如聊天对象、VRChat 的玩家或录音里的说话人。

<ObserverStructure node="USER" />

## 粒度 [#granularity]

一个事物对应模型或用户认为的一个人。一个部署只有一个用户本人，见 [User Statements · 用户本人的身份](./index.mdx#identity)。两个人其实是同一个时，见 [THING-5](../../core/model/thing.mdx#thing-5)。

## 身份 [#identity]

称呼是一份 [Name](../../core/rules/understanding.mdx#name)，用户填写或修改称呼时写入。账号和人是不同的事物，它们的关系由模型或用户写成[关系](../../core/rules/understanding.mdx#relation)，例如“QQ 号 123 是本人”。

模型认出的人用它自己范围内的依据新建，见 [THING-4](../../core/model/thing.mdx#thing-4)。
