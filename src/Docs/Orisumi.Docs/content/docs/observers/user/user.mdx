User 表示用户本人。用户作为 Observer 形成的每份 Observation，都通过 `observerVersionId` 引用它的一个版本。

<ObserverStructure node="USER" />

## 粒度 [#granularity]

一个实体对应一个人。一个部署只有一个用户，见 [User Statements · 用户本人的身份](./index.mdx#identity)。

## 身份 [#identity]

用户填写或修改称呼时，形成同一个实体的新版本。

## 引用 [#references]

用户本人没有引用。

## 事实时间 [#fact-time]

用户本人作为 Observer，本身不作为观测内容，没有事实时间。

## EntitySchema [#schema]

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-000000000006` |
| 显示名称 | 用户本人 |
| 说明 | 表示拥有这些数据的用户本人；用户确认、否定或陈述时，作为 Observer 对陈述负责。 |
| 资源名 | `users` |

| 字段 | 类型 | 必填 | 可空 | description |
| --- | --- | --- | --- | --- |
| `name` | `string` | 是 | 是 | 用户的称呼，没有填写时为 `null` |

## 示例 [#example]

Web 控制台创建用户本人时：

```json
{
  "name": null
}
```
