用户本人是拥有这些数据的人。用户确认、否定或陈述一件事时，这份 Observation 的 Observer 是用户本人，见 [OBSERVER-6](../../core/model/observer.mdx#observer-6)。例如用户在 Web 控制台中把 QQ 国际版从 QQ 中分出来，陈述这次修改的 Observation 引用用户本人。

用户通过 Web 控制台形成陈述：Web 控制台是写入方，用户本人是 Observer。

## 业务类型 [#types]

| 业务类型 | 用途 | 资源名 |
| --- | --- | --- |
| [User](./user.mdx) | Observer：用户本人 | `users` |

目前用户本人陈述的内容是[应用产品](../application-identity/application-product.mdx)，写法见 [Web · 应用](../../clients/web.mdx#applications)。

## 用户本人的身份 [#identity]

一个部署只有一个用户。Web 控制台第一次写入用户本人的陈述时，确保 User 的 EntitySchema 已保存，再列出 `users`：没有实体时创建一个，有实体时使用 EntityId 最小的那个。之后的陈述都引用它的当前版本。
