title: "User Statements"
description: "用户本人作为 Observer 的陈述"
---

用户本人是拥有这些数据的人。用户确认、否定或陈述一件事时，这份 Observation 的 Observer 是用户本人，形成方式是 `stated`，见 [OBSERVER-6](../../core/model/observer.mdx#observer-6)。例如用户否定一条推断时，写一份 [Review](../../core/rules/understanding.mdx#review-type)。

平时用户不审核，发现错误时才否定，见 [UNDERSTANDING-5](../../core/rules/understanding.mdx#understanding-5)。

## 业务类型 [#types]

| 业务类型 | 用途 | 资源名 |
| --- | --- | --- |
| [Person](./user.mdx) | 事物：一个人，用户本人是其中之一 | `people` |
| [Review](../../core/rules/understanding.mdx#review-type) | 用户的确认和否定 | `reviews` |

## 用户本人的身份 [#identity]

一个部署只有一个用户，所以识别依据是固定的：`scope` 为 `null`，`scheme` 为 `orisumi.user`，`value` 为 `owner`。
