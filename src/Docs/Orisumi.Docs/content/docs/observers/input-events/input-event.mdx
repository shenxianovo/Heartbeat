输入事件表达“在时刻 t 发生了一次键盘或鼠标操作”，由[输入事件 Observer](./index.mdx) 形成观测。

<ObserverStructure node="INPUT_CONTENT" />

## 粒度 [#granularity]

键盘事件记的是人的按键操作。一次按下和一次释放各自形成观测内容和 Observation；长按期间系统自动重复的按下被过滤掉，松开后再按下才是下一次操作。

例如按住 A 一秒，按下时记一条 `keyDown`，松开时记一条 `keyUp`。按 Shift+A 时，Shift 和 A 的按下、释放各记一条，组合键本身不单独成为事件。

## 身份 [#identity]

每次按下、每次释放都有自己的身份和 Observation。时间戳相同的不同事件分别记下。

## 引用 [#references]

目前没有引用。与设备的关联尚未确定。

## 事实时间 [#fact-time]

时间点型的 Observation：`startAt = endAt = t`，表示方式见 [Observation · 事实时间](../../core/model/observation.mdx#fact-time)。

### 具体按键 [#key]

是否记下具体按键，由输入事件 Observer 的用户设置决定，默认开启。开启时，按下和释放事件都带有 `key`；关闭时，事件仍有类别和对应的 Observation，只是省略 `key`。这个开关是采集设置，不是输入事件的字段。

`key` 记的是按了哪个键，与最终输入的文字无关。例如 Shift 和 A 各记各的键，“大写 A”这个结果不记；输入法最终生成的文字也不记。

## 示例 [#example]

开启具体按键记录时，按下事件带有 `key`。A 键的编码尚未确定，下例用占位文字代替：

```json
{
  "kind": "keyDown",
  "key": "<A 键标识>"
}
```

关闭具体按键记录时，省略 `key`：

```json
{
  "kind": "keyDown"
}
```
