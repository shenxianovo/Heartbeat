休眠状态表达“设备在这一段时间处于休眠或清醒”，由[设备状态 Observer](./index.mdx) 形成观测。这一页还是草案，EntitySchema 尚未分配 SchemaId。

<ObserverStructure node="DEVICE_CONTENT" />

## 粒度 [#granularity]

一份 Observation 表达设备处于休眠或清醒的一段时间。何时开始、补全或结束，取决于取得的状态边界证据，具体规则尚未确定。

## 身份 [#identity]

这份 Observation 的身份规则尚未确定。程序实例的身份见 [Device State · 程序实例](./index.mdx#instance)，设备的身份见 [Device · 身份](./device.mdx#identity)。

## 引用 [#references]

提到被观测设备的字段尚未定义。

## 事实时间 [#fact-time]

事实时间是状态的开始和结束边界，两者都已知时是 `[startAt, endAt)`，表示方式见 [Observation · 事实时间](../../core/model/observation.mdx#fact-time)。

## EntitySchema [#schema]

| 项目 | 值 |
| --- | --- |
| SchemaId | 待定 |
| 显示名称 | 设备休眠与清醒状态 |
| 说明 | 表达设备处于休眠或清醒状态的一段事实；事实时间是已知的状态边界。 |
| 资源名 | 待定 |

| 字段 | 类型 | 必填 | 可空 | description |
| --- | --- | --- | --- | --- |
| `state` | `string` | 待定 | 待定 | `awake` 表示清醒，`asleep` 表示休眠 |

## 示例 [#example]

提到设备的字段尚未定义，示例只有状态字段：

```json
{
  "state": "asleep"
}
```

## 待定 [#open]

- SchemaId、资源名，以及字段的必填和可空。
- 身份规则，以及怎样提到设备。
- 怎样用系统的休眠和唤醒证据确定边界。
- 启动时怎样取得状态。
- 停止或崩溃后的采集空白。
