应用产品表示用户认知中的一款软件，例如 QQ。它是一个[事物](../../core/model/thing.mdx)。各设备、各平台上的 QQ 安装都是本机应用，它们的跨设备线索由[线索归属](./application-membership.mdx)指向 QQ 这个产品，规则见 [Application Identity · 归属](./index.mdx#membership)。

应用产品由应用识别 Observer 新建，名字是一份 [Name](../../core/rules/understanding.mdx#name)。

<ObserverStructure node="APPLICATION_PRODUCT" />

## 粒度 [#granularity]

一个事物对应一款软件。应用识别 Observer 把下面的标准交给模型：

| 情况 | 产品 |
| --- | --- |
| 同一款软件在不同平台上的版本，例如 macOS 和 Android 上的 QQ | 同一个 |
| 版本升级、不同的 CPU 架构、商店版和官网版 | 同一个 |
| 软件改名后仍是原来那款 | 同一个 |
| 名称相同、出自同一家公司或功能相近 | 按实际是不是同一款软件判断 |
| 轻量版、国际版、分叉版本 | 按实际关系判断 |

## 身份 [#identity]

应用识别 Observer 认出一款新的软件时新建一个产品，用自己范围内的依据，见 [THING-4](../../core/model/thing.mdx#thing-4)：

| 识别依据 | 值 |
| --- | --- |
| `scope` | 应用识别 Observer 的 EntityId |
| `scheme` | `application-identity.product` |
| `value` | 模型给出的产品名称 |

名称不是产品的身份。软件改名时写一份新的 Name，产品不变。
