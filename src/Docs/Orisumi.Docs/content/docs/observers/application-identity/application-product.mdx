title: "Application Product"
description: "用户认知中的一款软件，内容只有名称"

应用产品表示用户认知中的一款软件，例如 QQ。各设备、各平台上的 QQ 安装都是本机应用，它们的跨设备线索由[线索归属](./application-membership.mdx)指向 QQ 这个产品，规则见 [Application Identity · 归属](./index.mdx#membership)。

应用产品由应用识别 Observer 写入。它被线索归属引用，自己不作为观测内容，所以没有 Observation，这个产品的责任和依据在线索归属的 Observation 上。

<ObserverStructure node="APPLICATION_PRODUCT" />

## 粒度 [#granularity]

一个实体对应一款软件。应用识别 Observer 把下面的标准交给模型：

| 情况 | 产品 |
| --- | --- |
| 同一款软件在不同平台上的版本，例如 macOS 和 Android 上的 QQ | 同一个 |
| 版本升级、不同的 CPU 架构、商店版和官网版 | 同一个 |
| 软件改名后仍是原来那款 | 同一个 |
| 名称相同、出自同一家公司或功能相近 | 按实际是不是同一款软件判断 |
| 轻量版、国际版、分叉版本 | 按实际关系判断 |

## 身份 [#identity]

应用识别 Observer 认出一款新的软件时新建一个产品。产品没有识别依据，EntityId 由后端生成，名称不参与身份。

内容写入一次后不再变化：线索的加入和移出是线索归属的变化，名称保持第一次判断时的样子。

## 引用 [#references]

应用产品没有引用。[线索归属](./application-membership.mdx)引用它。
