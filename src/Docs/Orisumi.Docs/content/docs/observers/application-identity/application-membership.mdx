线索归属表示一次判断：一条跨设备线索属于一个[应用产品](./application-product.mdx)，例如 `macos.bundle-id` 的 `com.tencent.qq` 属于 QQ。它由应用识别 Observer 形成，形成方式是 `inferred`。

<ObserverStructure node="APPLICATION_MEMBERSHIP" />

## 粒度 [#granularity]

一次判断一份 Observation。QQ 在 macOS 和 Android 上各有一条线索，这是两次判断，各有自己的依据。同一条线索重新判断时形成新的 Observation，旧判断保留，见 [UNDERSTANDING-2](../../core/rules/understanding.mdx#understanding-2)。

## 身份 [#identity]

线索归属没有识别依据，每次判断都新建。

| 变化 | 结果 |
| --- | --- |
| 应用识别 Observer 判断一条未归属的线索 | 新建 |
| 换了模型后重新判断 | 新建，再写一份 `supersede` 的 Review 取代旧判断 |
| 用户发现归错了 | 用户写一份 `deny` 的 Review，判断保持原样 |

## 引用 [#references]

| 字段 | 目标 |
| --- | --- |
| `identifierId` | 这条[应用线索](./index.mdx#identifiers) |
| `productId` | 线索属于的[应用产品](./application-product.mdx) |

## 事实时间 [#fact-time]

`startAt`、`endAt` 和 `timeZone` 都是 `null`：这款软件从什么时候起有这条线索，判断时不知道，见 [OBSERVATION-5](../../core/model/observation.mdx#observation-5)。
