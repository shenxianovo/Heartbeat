助手会话 Observer 程序实例是一个事物，例如这台 Mac 上运行的助手会话 Observer。它用这份描述说明自己，见 [OBSERVER-9](../../core/model/observer.mdx#observer-9)，它形成的每份 Observation 都通过 `observerVersionId` 引用描述的一个版本。

<ObserverStructure node="ASSISTANT_SESSIONS" />

## 粒度 [#granularity]

一份描述对应一个程序实例。程序实例的划分见 [Assistant Sessions · 程序实例](./index.mdx#instance)。

## 身份 [#identity]

EntityId 由托管方保存，重启、升级和重装后沿用，见 [OBSERVER-4](../../core/model/observer.mdx#observer-4)。平台、主机名或程序版本变化时，形成描述的新版本；之后的 Observation 引用新版本。

## EntitySchema [#schema]

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-000000000007` |
| 显示名称 | 助手会话 Observer |
| 说明 | 描述一个助手会话 Observer 程序实例：它运行的平台、主机名和程序版本。 |
| 资源名 | `assistant-sessions-observers` |
| `kind` | `observation` |
| `immutable` | `false` |

| 字段 | 类型 | 必填 | 可空 | description |
| --- | --- | --- | --- | --- |
| `platform` | `string` | 是 | 否 | 运行的平台：`macos`、`windows` 或 `linux` |
| `hostName` | `string` | 是 | 是 | 本机的名称，读不到时为 `null` |
| `programVersion` | `string` | 是 | 否 | 程序的版本，即安装包的版本 |

## 示例 [#example]

```json
{
  "platform": "macos",
  "hostName": "Shenxianovo-Mac",
  "programVersion": "0.1.0"
}
```
