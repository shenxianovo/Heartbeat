---
title: "Assistant Subagent"
description: "子 Agent 会话和发起它的会话之间的关系"
---

子 Agent 关系表示一个[助手会话](./assistant-session.mdx)是由另一个会话发起的，例如 Claude Code 为读网页派出一个 `web-fetch`。它由助手会话 Observer 形成，形成方式是 `direct`。

<ObserverStructure node="ASSISTANT_SUBAGENT" />

## 粒度 [#granularity]

一个子 Agent 的会话对应一份 Observation。

| 产品 | 子 Agent 的会话 | 发起它的会话 |
| --- | --- | --- |
| Claude Code | `subagents/agent-<agentId>.jsonl` 中的记录，带 `agentId` | 文件所在目录的 `sessionId` |
| Codex | `session_meta` 的 `source.subagent` 存在的 rollout 文件 | `source.subagent.thread_spawn.parent_thread_id` |

## 身份 [#identity]

| 识别依据 | 值 |
| --- | --- |
| `scope` | `null` |
| `scheme` | `claude-code.subagent` 或 `codex.subagent` |
| `value` | 子 Agent 会话的来源标识 |

## 引用 [#references]

| 字段 | 目标 |
| --- | --- |
| `sessionId` | 子 Agent 的会话 |
| `parentSessionId` | 发起它的会话 |

## 事实时间 [#fact-time]

来源没有单独记下子 Agent 开始的时刻，事实时间未知，由读取方从交互的时间计算。

## EntitySchema [#schema]

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-00000000000b` |
| 显示名称 | 子 Agent 关系 |
| 说明 | 表示一个子 Agent 的会话和发起它的会话之间的关系。一个子 Agent 的会话一份 Observation。 |
| 资源名 | `assistant-subagents` |
| `kind` | `observation` |
| `immutable` | `true` |

| 字段 | 类型 | 必填 | 可空 | description |
| --- | --- | --- | --- | --- |
| `sessionId` | `reference`，目标为事物 | 是 | 否 | 子 Agent 的会话 |
| `parentSessionId` | `reference`，目标为事物 | 是 | 否 | 发起这个子 Agent 的会话 |
| `agentName` | `string` | 是 | 是 | 子 Agent 的类型或路径：Claude Code `meta.json` 的 `agentType`，Codex 的 `agent_path`。来源没有给出时为 `null` |
| `spawnCallId` | `string` | 是 | 是 | 父会话中发起这个子 Agent 的工具调用标识，对应父会话中工具调用交互的 `callId`；来源没有给出时为 `null` |
