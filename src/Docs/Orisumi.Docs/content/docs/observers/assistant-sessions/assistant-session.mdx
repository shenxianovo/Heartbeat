---
title: "Assistant Session"
description: "Claude Code 或 Codex 中的一个会话"
---

助手会话表示来源中的一个会话，例如 Claude Code 里讨论文档结构的那个会话，或者它为读网页派出的子 Agent 的会话。会话被它的每次[交互](./assistant-interaction.mdx)引用，自己不作为观测内容，所以没有事实时间：会话从几点到几点，由读取方从交互的时间计算。

<ObserverStructure node="ASSISTANT_SESSION" />

## 粒度 [#granularity]

来源的一个会话对应一个实体。会话的标题由来源生成或由用户修改，标题变化时形成同一个实体的新版本，之后的交互引用新版本。

子 Agent 有自己的会话，用 `parentSessionVersionId` 指向发起它的会话：

| 产品 | 子 Agent 的会话 | 父会话 |
| --- | --- | --- |
| Claude Code | `subagents/agent-<agentId>.jsonl` 中的记录，带 `agentId` | 文件所在目录的 `sessionId` |
| Codex | `session_meta` 的 `source.subagent` 存在的 rollout 文件 | `source.subagent.thread_spawn.parent_thread_id` |

子 Agent 的会话引用父会话，所以先读到子 Agent 的文件时，助手会话 Observer 先形成父会话，再形成子 Agent 的会话。

## 身份 [#identity]

身份是 `(product, sourceSessionId)`。Claude Code 的 `sessionId` 和 `agentId`、Codex 的会话 `id` 都由来源生成，在同一个产品中唯一。身份登记保存这个身份到 EntityId 的映射，见 [Assistant Sessions · 程序实例](./index.mdx#instance)。

同一个会话的文件被复制或移动，例如 Codex 把会话移进归档目录，身份不变，仍是同一个实体。

## 引用 [#references]

| 字段 | 目标 |
| --- | --- |
| `parentSessionVersionId` | 发起这个子 Agent 的会话 |

## EntitySchema [#schema]

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-000000000008` |
| 显示名称 | 助手会话 |
| 说明 | 表示 Claude Code 或 Codex 中的一个会话，包括子 Agent 的会话；一个来源会话对应一个实体，标题变化时形成新版本。会话本身没有事实时间，会话中每次交互的时间写在引用交互的 Observation 上。 |
| 资源名 | `assistant-sessions` |

| 字段 | 类型 | 必填 | 可空 | description |
| --- | --- | --- | --- | --- |
| `product` | `string` | 是 | 否 | 产生会话的产品：`claude-code` 或 `codex` |
| `sourceSessionId` | `string` | 是 | 否 | 来源中会话的标识：Claude Code 主会话的 `sessionId`、子 Agent 的 `agentId`，或 Codex 的会话 `id` |
| `title` | `string` | 是 | 是 | 会话的标题：Claude Code 最近一条 `custom-title`，子 Agent 取 `meta.json` 的 `description`；Codex 取 `session_index.jsonl` 的 `thread_name`。来源没有标题时为 `null` |
| `client` | `string` | 是 | 是 | 来源记下的客户端：Claude Code 的 `entrypoint`，例如 `cli` 或 `claude-desktop`；Codex 的 `originator`。来源没有记下时为 `null` |
| `parentSessionVersionId` | `reference` | 是 | 是 | 子 Agent 的会话引用发起它的会话；主会话为 `null` |
| `agentName` | `string` | 是 | 是 | 子 Agent 的类型或路径：Claude Code `meta.json` 的 `agentType`，Codex 的 `agent_path`。主会话或来源没有给出时为 `null` |
| `spawnCallId` | `string` | 是 | 是 | 父会话中发起这个子 Agent 的工具调用标识，对应父会话中工具调用交互的 `callId`；主会话或来源没有给出时为 `null` |

## 示例 [#example]

Claude Code 为读网页派出的子 Agent 的会话：

```json
{
  "product": "claude-code",
  "sourceSessionId": "ac3f8c436510b138e",
  "title": "Read Slack flowchart article",
  "client": "claude-desktop",
  "parentSessionVersionId": "019e2c41-7a10-7000-8000-0000000001a1",
  "agentName": "web-fetch",
  "spawnCallId": "toolu_012dcHp4quCzvxk4k8nLxQqy"
}
```
