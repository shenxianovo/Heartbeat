title: "Assistant Session"

助手会话表示来源中的一个会话，例如 Claude Code 里讨论文档结构的那个会话，或者它为读网页派出的子 Agent 的会话。它是一个[事物](../../core/model/thing.mdx)，被它的每次[交互](./assistant-interaction.mdx)提到。会话从几点到几点，由读取方从交互的时间计算。

日志和索引文件各给出会话的一部分，日志还可能被重读，所以会变的内容都写成单独的 Observation：标题是 [Name](../../core/rules/understanding.mdx#name)，发起关系是[子 Agent 关系](./assistant-subagent.mdx)，见 [IDENTITY-5](../../core/rules/identity.mdx#identity-5)。

## 粒度 [#granularity]

来源的一个会话对应一个事物，子 Agent 的会话也是一个事物。

## 身份 [#identity]

Claude Code 的 `sessionId` 和 `agentId`、Codex 的会话 `id` 都由来源生成，在同一个产品中唯一。

| 识别依据 | 值 |
| --- | --- |
| `scope` | `null` |
| `scheme` | `claude-code.session` 或 `codex.session` |
| `value` | `sessionId`、`agentId` 或会话 `id` |

同一个会话的文件被复制或移动，例如 Codex 把会话移进归档目录，身份不变。用户删除一个会话后，识别依据随它删除；之后读到这个会话的数据时，它是一个新事物，见 [IDENTITY-7](../../core/rules/identity.mdx#identity-7)。

## 标题 [#titles]

来源中一次不同的标题写成一份 Name，形成后不再变化。Codex 把一个会话命名为“整理文档结构”，之后用户改成“重写 Observer 文档”，这是两份 Name。

| 产品 | 来源 |
| --- | --- |
| Claude Code | 日志中的 `custom-title` 和 `agent-name`；子 Agent 取 `meta.json` 的 `description` |
| Codex | `session_index.jsonl` 的 `thread_name`。这个文件只追加，每次改名有一行 |

| 识别依据 | 值 |
| --- | --- |
| `scope` | `null` |
| `scheme` | `codex.session-title` 或 `claude-code.session-title` |
| `value` | Codex 是会话 `id` 和 `updated_at`，Claude Code 是 `sessionId` 和标题，都用换行连接 |

Claude Code 的标题行没有时间和标识，同一行反复写入，所以用标题本身区分。标题回到之前用过的值时，这次变化不形成新的 Name。

| 产品 | 事实时间 |
| --- | --- |
| Codex | 时间点：`updated_at` |
| Claude Code | 未知，两个边界都是 `null` |

形成方式是 `direct`，`timeZone` 为 `null`。
