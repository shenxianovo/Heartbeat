前台状态 Observer 程序实例是一个业务实体，例如这台 Mac 上运行的前台状态 Observer。它形成的每份 Observation 都通过 `observerVersionId` 引用它的一个版本。

<ObserverStructure node="FOREGROUND_STATE" />

## 粒度 [#granularity]

一个实体对应一个程序实例。程序实例的划分见 [Foreground State · 程序实例](./index.mdx#instance)。

## 身份 [#identity]

EntityId 保存在身份文件中，重启和升级后沿用，见 [OBSERVER-4](../../core/model/observer.mdx#observer-4)。平台、主机名或程序版本变化时，形成同一个实体的新版本；之后的 Observation 引用新版本。

## 引用 [#references]

程序实例没有引用。

## 事实时间 [#fact-time]

程序实例是 Observer，本身不作为观测内容，没有事实时间。

## EntitySchema [#schema]

| 项目 | 值 |
| --- | --- |
| SchemaId | `019e1bbb-ec00-7000-8000-000000000003` |
| 显示名称 | 前台状态 Observer |
| 说明 | 表示一个前台状态 Observer 程序实例，保存它运行的平台、主机名和程序版本；它作为 Observer 对前台应用时段和窗口标题时段的观测负责。 |
| 资源名 | `foreground-state-observers` |

| 字段 | 类型 | 必填 | 可空 | 含义 |
| --- | --- | --- | --- | --- |
| `platform` | `string` | 是 | 否 | 运行的平台：`macos`、`windows`、`android` 或 `linux` |
| `hostName` | `string` | 是 | 是 | 本机的名称，读不到时为 `null` |
| `programVersion` | `string` | 是 | 否 | 程序的版本 |

## 示例 [#example]

```json
{
  "platform": "macos",
  "hostName": "Shenxianovo-Mac",
  "programVersion": "0.1.0"
}
```
