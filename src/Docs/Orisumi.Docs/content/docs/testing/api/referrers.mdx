## 为什么验证 [#why]

引用方查询按路径和业务类型筛选后分页，目标删除不抹去引用。约定见 [引用方](../../api/reading.mdx#referrers)。

## 前置条件 [#setup]

HTTP 用例经真实 API 和独立的 PostgreSQL 数据库运行。Runtime 使用临时数据目录；Observer 的读数、日志和模型回答由测试控制。实际运行的补充证据单独说明，见 [测试分工](../index.mdx#kinds)。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 筛选 path 和 resourceName | 只返回匹配项，筛选先于分页 |
| 嵌套字段名含斜线和波浪号 | path 按 JSON Pointer 转义 |
| 分别查 current 和 all，升序和降序分页 | 返回对应版本范围，页间不重复 |
| 删除目标后再次查询 | 引用方、path 和 targetVersionId 保留 |
