export const caseId = 'api-reading';

## 为什么验证 [#why]

读回保留版本的完整结构，批量结果与输入顺序一致。约定见 [Reading](../../api/reading.mdx)。

## 前置条件 [#setup]

HTTP 用例经真实 API 和独立的 PostgreSQL 数据库运行。Runtime 使用临时数据目录；Observer 的读数、日志和模型回答由测试控制。实际运行的补充证据单独说明，见 [测试分工](../index.mdx#kinds)。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 读取版本、实体和版本链 | 版本身份、Schema、作者、描述、formation、InputSet、事实时间和业务 content，当前版本正确，版本链从首版到当前版 |
| 写入带时区偏移和七位小数的事实时间 | UTC 表示，精度截断到微秒 |
| 批量读取包含已保存、从未出现和已删除的版本 | 分别返回 found、not_found、deleted，保留顺序和重复项 |
| 批量请求超过 256 个 VersionId | 400 |
| 按 ID 读取未知或已删除实体 | 分别为 404 和 410 |
| 读取事物 | 返回 category、entityId、schemaId、keys 和 name，没有 versionId |
| 按 formation 查询 | 只返回形成方式匹配的 Observation |

## 测试实现 [#implementation]

方法位于 `tests/Orisumi.Integration.Tests/`：

- 批量状态、顺序、重复和上限：`WriteApiTests.DeletionRemovesRecognitionAndBatchReadPreservesOrderDuplicatesAndStatus`。
- 完整成员、版本链和时间：`WriteApiTests.ConcurrentRecognitionPreservesOneChainAndHttpBoundariesRemainExplicit`。

- 事物表示：`UnderstandingApiTests.ThingNamesPreferPeopleThenLatestAndDeletionRetainsReferences`。
- 描述、作者、formation 和未知事实时间：`UnderstandingApiTests.FormationDescriptionsAuthorsAndImmutableContentFollowTheContract`。
