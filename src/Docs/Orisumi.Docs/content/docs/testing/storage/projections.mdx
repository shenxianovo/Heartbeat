## 为什么验证 [#why]

重建后的查询结果应与逐次写入一致，已删除目标的身份仍可追溯。约定见 [Queries](../../storage/queries.mdx)。

## 前置条件 [#setup]

HTTP 用例经真实 API 和独立的 PostgreSQL 数据库运行。Runtime 使用临时数据目录；Observer 的读数、日志和模型回答由测试控制。实际运行的补充证据单独说明，见 [测试分工](../index.mdx#kinds)。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 删除 Observation | 它的版本标为已删除，指向它的 Review 和引用仍能追溯 |
| 删除引用目标 | 引用方保留原 path 和目标版本 |
| 清空投影后重建 | 事物、Review、历史、当前版本、引用和 Observation 的 current/all 查询与之前相同 |
| 重建投影 | 删除后的依据不恢复，写入流中的描述版本不丢失 |
