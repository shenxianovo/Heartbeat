## 为什么验证 [#why]

会话页把一天的[助手交互](../../observers/assistant-sessions/assistant-interaction.mdx)按会话组织成可以读的对话。分组、排序和配对都依据交互的字段和事实时间，工具输出按位置从原始记录中读出。约定见 [Web · 会话](../../clients/web.mdx#sessions)。

## 前置条件 [#setup]

后端由路由拦截在内存中模拟，放进同一天的 Claude Code 和 Codex 会话，包括一个子 Agent 的会话。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 打开会话页 | 最近有交互的会话在前，子 Agent 的会话缩进在父会话下面；页头写出会话数、你说的句数和工具调用数 |
| Claude Code 的助手回复只有结束边界 | 按结束的时刻排进对话 |
| 两个并行的工具调用，结果按相反的顺序返回 | 每个结果配到 `callId` 相同的调用；没有调用的结果单独一行 |
| 切到“对话” | 只有消息 |
| 切到“过程”，点开一次工具调用 | 显示参数，结果从原始记录中读出 |
| 切到“全部” | 出现上下文；推理和上下文默认收起 |
| 这一天没有交互，或资源名还没有登记 | 显示空状态 |

## 测试实现 [#implementation]

- 分组、排序、子 Agent 的缩进、工具调用的配对和视图的筛选：`src/lib/conversations.test.ts`。
- 会话的排列、页头的统计、视图的切换和从原始记录读出的工具输出：`tests/e2e/sessions.spec.ts`。
- 空状态：未覆盖。
