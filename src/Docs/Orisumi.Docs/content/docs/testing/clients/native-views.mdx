export const caseId = 'native-views';

## 为什么验证 [#why]

客户端展示的数据来自后端和本地两处，发送前后同一份 Observation 不能显示两次；Observer 停止后数据仍要可读。约定见 [Overview · 最近的数据](../../clients/index.mdx#today) 和 [Runtime · 读取](../../clients/runtime.mdx#reading)。

## 前置条件 [#setup]

Runtime 使用独立的数据目录，连接通过 `WebApplicationFactory` 启动的 API。读取的界面检查在 macOS 客户端中实际运行。

## 操作与预期结果 [#steps]

| 操作 | 预期结果 |
| --- | --- |
| 提交一份 Observation 后、发送前读取 | 结果中有它，`state` 为 `pending` |
| 发送完成后再读取 | 它只出现一次，`state` 为 `saved` |
| 读取进行中的 Observation | `state` 为 `draft` |
| 停用 Observer 后读取 | 仍能读到它的数据 |
| 后端不可用时读取 | 返回本地的数据，`complete` 为 `false`，`error` 说明原因 |
| 用 `versions` 读取一个实体的旧版本，这个实体已有更新的版本 | 返回的是指定的旧版本 |
| 被引用的版本已在后端删除 | 它出现在 `missing` 中 |
| 翻页期间有新的数据提交 | 各页不重复也不遗漏第一页时的快照 |
| 安装一个没有专用视图的 Observer，在 macOS 客户端中打开 | 详情显示状态、发送和最近的 Observation |
| 前台状态 Observer 在 macOS 客户端中 | 显示今天的前台应用视图；断网时标明可能不完整 |

## 测试实现 [#implementation]

以下方法位于 `tests/Orisumi.Integration.Tests/`，对应本页的预期范围：

- 发送前读到 `draft`，发送后同一份 Observation 只出现一次且为 `saved`；后端删除后不再出现，之后离线也不出现本地副本：`RuntimeReadingTests.UploadDoesNotDuplicateAndKnownDeletionDoesNotReappearOffline`。
- 翻页期间有新的时段提交，各页来自第一页的快照，不重复：`RuntimeReadingTests.PaginationKeepsOneSnapshotWhileCollectionContinues`。
- macOS 客户端经 Runtime 读取今天的时段、分页和游标过期后重读，`versions` 报告缺失的内容不再显示，`versions` 报告错误时结果标为不完整：`OrisumiClient` 的 `ObservationReaderTests`；对真实 Runtime 读到进行中的时段、停用后仍能读取：`RuntimeIntegrationTests.enableUninstallReinstallKeepIdentityAndTodayReads`（设置 `ORISUMI_APP` 时运行）。
- 未覆盖：`versions` 读取旧版本和已删除的版本。macOS 客户端的界面按 [macOS](../../clients/macos.mdx) 实际运行检查。
