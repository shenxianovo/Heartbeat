# Orisumi Feature Map

本页用于选择验证入口。行为以链接的长期文档为准。表中的 `orisumi` 是 Orisumi.Dev 的命令，安装见 [Orisumi.Dev README · 安装](../../../../../tools/Orisumi.Dev/README.md#安装)。

| 能力 | 用户入口 | 验证入口 | 权威文档 | 证据限制 |
| --- | --- | --- | --- | --- |
| 模型规则 | `dotnet test --project tests/Orisumi.Model.Tests/Orisumi.Model.Tests.csproj` | `orisumi verify checks --scope all`、变更选择的 `model-tests` | [测试分工](../../../../../src/Docs/Orisumi.Docs/content/docs/testing/index.mdx) | Core 与 Application 的规则，存储为内存实现；不覆盖 HTTP、数据库和 Observer 运行 |
| 实体 API 与存储 | `orisumi env up api` 后 <http://localhost:8080/api>；文档站接口页的 Playground | `orisumi verify checks` 中的集成测试（独立 PostgreSQL），写入见 `WriteApiTests`，二进制内容的上传、读取和保留见 `BinaryContentTests`；`orisumi verify scenarios api` | [API](../../../../../src/Docs/Orisumi.Docs/content/docs/api/index.mdx)、[Storage](../../../../../src/Docs/Orisumi.Docs/content/docs/storage/index.mdx)、[API README](../../../../../src/Backend/Orisumi.Api/README.md) | `verify scenarios api` 只覆盖写入、读取和拒绝，不覆盖 `/contents/{digest}`；吞吐只在本机测过 |

| 助手会话 Observer（macOS） | 随 macOS 客户端附带；单独构建 `orisumi observers pack assistant-sessions --target osx-arm64 --output <目录> --sign -`，再用 Runtime 的 `--run assistant-sessions` 运行 | `orisumi verify checks` 中的 `Assistant*Tests`（合成日志；原始记录和删除用独立 PostgreSQL 与真实 API）；另按[运行说明 · 验证](../../../../../src/Observers/Orisumi.Observer.AssistantSessions/README.md#验证)读取本机真实日志 | [Assistant Sessions](../../../../../src/Docs/Orisumi.Docs/content/docs/observers/assistant-sessions/index.mdx)、[运行说明](../../../../../src/Observers/Orisumi.Observer.AssistantSessions/README.md) | Windows 和 Linux 没有运行验证；首次运行会导入本机全部会话，实际运行时用临时数据目录、来源样本和临时后端；未覆盖的预期列在各 Case 页 |
| 应用识别 Observer | 安装包，由服务方式的 Runtime 运行：`orisumi observers pack application-identity --target <RID> --output <目录>` 构建，启动和配对见 [Runtime README](../../../../../src/Observers/Orisumi.Observer.Runtime/README.md#在本地以服务方式运行)；Key 从 Runtime 的环境继承，型号和间隔是实例设置 | `orisumi verify checks` 中的集成测试：`ApplicationIdentityTests`（SDK、真实 API、独立 PostgreSQL、模型替身）和 `ApplicationModelTests`（HTTP 替身）；真实的 OpenAI 调用在临时环境中单独运行并保存结果 | [Application Identity](../../../../../src/Docs/Orisumi.Docs/content/docs/observers/application-identity/index.mdx)、[ADR · 应用识别](../../../../../src/Docs/Orisumi.Docs/content/docs/adr/application-identity.mdx)、[ADR · Runtime 与进程托管](../../../../../src/Docs/Orisumi.Docs/content/docs/adr/observer-runtime.mdx)、[程序 README](../../../../../src/Observers/Orisumi.Observer.ApplicationIdentity/README.md) | 自动测试不调用 OpenAI，模型判断的质量要看真实调用的结果；没有杀掉操作系统进程 |
| Observer 管理与服务方式的 Runtime | Web 的 `/hosts`；Mac 主窗口侧栏的“设备”；`/api/hosts`、`/api/observer-instances`、`/api/runtime/*`；服务方式见 [Runtime README](../../../../../src/Observers/Orisumi.Observer.Runtime/README.md) | `orisumi verify checks` 中的 `ManagementApiTests`、`RuntimeManagementTests`、`ProjectionTests`；Web 的 `management.test.tsx`；配对、远程停用、重新接入和服务退出在临时环境中实际运行 | [Hosting · Management](../../../../../src/Docs/Orisumi.Docs/content/docs/hosting/management.mdx)、[API · Management](../../../../../src/Docs/Orisumi.Docs/content/docs/api/management.mdx)、[Hosting · Server](../../../../../src/Docs/Orisumi.Docs/content/docs/hosting/server.mdx) | 没有长期离线、断电和跨主机公网部署的测试；只支持一个 API 进程 |
