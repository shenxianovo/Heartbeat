# Heartbeat Feature Map

本页用于选择验证入口，行为语义以链接的长期文档为准。Developer CLI 命令前加 `dotnet run --project tools/Heartbeat.Dev --`。

| 能力 | 用户入口 | 验证入口 | 权威文档 | 证据限制 |
| --- | --- | --- | --- | --- |
| 实体 API | 四类实体的 `PUT /api/entities/...`、`GET /api/entities/{id}` | `verify full` 或变更选择的集成测试；另检查构建生成的 OpenAPI | [实体协议](../../../../../src/Docs/Heartbeat.Docs/content/docs/api/index.mdx)、[存储约定](../../../../../src/Docs/Heartbeat.Docs/content/docs/storage/index.mdx)、[测试边界](../../../../../src/Docs/Heartbeat.Docs/content/docs/testing/index.mdx) | 真实 API 宿主和独立 PostgreSQL；不覆盖浏览器或部署 |
| 前台状态 Observer（macOS） | `dotnet run --project src/Observers/Heartbeat.Observer.ForegroundState`；`--api`、`--identity-file` 选择服务与前台状态实例 | `verify full` 或变更验证；另在 macOS 用临时身份文件和独立 API、数据库运行并读回 | [观测语义](../../../../../src/Docs/Heartbeat.Docs/content/docs/observers/foreground-state.mdx)、[运行说明](../../../../../src/Observers/Heartbeat.Observer.ForegroundState/README.md)、[主体与身份职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0002-observer-capabilities-and-platform-clients.mdx) | 自动测试覆盖身份文件与提交；实际运行另证明 macOS 原生读取，当前仅单次前台应用读数 |
| 文档站 | 文档端口 `/core`、`/observers` 及观测定义、API 概览 `/api`、ADR | 文档目录 `pnpm types:check`、`pnpm build`；实际页面、搜索、导出与资源链接 | [文档站 README](../../../../../src/Docs/Heartbeat.Docs/README.md)、[应用时段 Schema](../../../../../src/Docs/Heartbeat.Docs/content/docs/observers/schemas/foreground-application-interval.mdx)、[文档入口责任](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0001-documentation-source-of-truth.mdx) | 页面检查只证明所检查的页面和交互 |
| 测试报告 | `/testing/reports/integration` | 文档检查与构建；实际报告、搜索、筛选、详情和无报告状态 | [报告职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0007-developer-cli-and-verification.mdx)、[文档站 README](../../../../../src/Docs/Heartbeat.Docs/README.md) | 展示真实 TUnit JSON；页面不执行测试 |
| 本地环境 | `env up/down/status/logs [all\|api\|docs\|db]`，生产构建加 `--release` | 工具测试；独立 Compose 项目验证单栈和全部启动、就绪、停止、数据卷保留 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md)、[启动职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0005-backend-project-organization.mdx#docker-启动)、[HTTP 入口](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0006-unified-http-entry.mdx) | 本地验证不证明部署环境；真实环境停止保留数据卷 |
| 开发验证 | `verify full/changed/closeout` | `--plan` 核对选择；执行后检查清单、结果和日志；失败和取消边界测试 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md)、[职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0007-developer-cli-and-verification.mdx) | 容器运行与页面检查另行选择 |
| 质量与规模 | `quality --base REF`、`quality loc` | 分类与发现解析测试；真实扫描；可编译隔离基线验证变化比较 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md)、[质量职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0007-developer-cli-and-verification.mdx) | 发现供审查；扫描失败仍失败；历史编译失败不能称为比较通过 |
| 验证证据 | `artifacts list/prune` | 成功、失败、取消的清单与日志；保留并集、预览和删除验证 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md) | 清理验证使用临时证据目录，不操作用户历史数据 |
