# Heartbeat Feature Map

本页用于选择验证入口。行为以链接的长期文档为准。表中的 `hb` 是 Heartbeat.Dev 的命令，安装见 [Heartbeat.Dev README · 安装](../../../../../tools/Heartbeat.Dev/README.md#安装)。

| 能力 | 用户入口 | 验证入口 | 权威文档 | 证据限制 |
| --- | --- | --- | --- | --- |
| 模型规则 | `dotnet test --project tests/Heartbeat.Model.Tests/Heartbeat.Model.Tests.csproj` | `hb verify full`、变更选择的 `model-tests` | [测试分工](../../../../../src/Docs/Heartbeat.Docs/content/docs/testing/index.mdx) | Core 与 Application 的规则，存储为内存实现；不覆盖 HTTP、数据库和 Observer 运行 |
| 实体 API 与存储 | `hb env up api` 后 <http://localhost:8080/api>；文档站接口页的 Playground | `hb verify full` 或变更选择的 `integration-tests`（`EntityApiTests`、`ReferrerApiTests`，独立 PostgreSQL）；`hb verify scenarios api` | [API](../../../../../src/Docs/Heartbeat.Docs/content/docs/api/index.mdx)、[Storage](../../../../../src/Docs/Heartbeat.Docs/content/docs/storage/index.mdx)、[API README](../../../../../src/Backend/Heartbeat.Api/README.md) | 集成测试覆盖全部接口，包括列出引用方、部分拒绝、时间查询与多实例冲突；`hb verify scenarios api` 只覆盖提交、读取和拒绝；吞吐只在本机测过 |
| .NET SDK 与前台状态 Observer（macOS） | `dotnet run --project src/Observers/Heartbeat.Observer.ForegroundState`；`--identity-file`、`--applications-file`、`--state-file` 选择身份与状态文件，`--backend` 选择 API，`--samples` 限定验证次数 | `hb verify full` 或变更验证（`ObserverSdkTests` 等）；另在 macOS 用临时文件对 `hb env up api --temp` 的环境实际运行，用 API 读回已结束的时段；Observer 场景加入后用 `hb verify scenarios` | [Submission](../../../../../src/Docs/Heartbeat.Docs/content/docs/observers/submission/index.mdx)、[Foreground State](../../../../../src/Docs/Heartbeat.Docs/content/docs/observers/application-activity/index.mdx)、[SDK README](../../../../../src/Observers/Heartbeat.Observer.Sdk/README.md)、[运行说明](../../../../../src/Observers/Heartbeat.Observer.ForegroundState/README.md) | 自动测试覆盖草稿与恢复、重试与拆批、部分拒绝、Schema 登记、上传和本机应用被删除后的恢复，不调用 macOS 原生接口；真实休眠、长时间断网需另测 |
| 文档站 | `hb env up docs`，或者文档目录 `pnpm dev`；文档端口的 `/core`、`/observers`、`/api`、`/storage`、`/testing`、`/adr` | 文档目录 `pnpm docs:check`、`pnpm test`、`pnpm types:check`、`pnpm build`；实际页面、搜索、导出与资源链接 | [文档站 README](../../../../../src/Docs/Heartbeat.Docs/README.md)、[ADR · 文档的权威与传播](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/documentation-authority.mdx)、仓库根目录的 [AGENTS.md](../../../../../AGENTS.md) | 页面检查只证明所检查的页面和交互 |
| 文档引用图 | 文档站 Start 分区的 `/start/graph` | 文档站检查与 `build-graph.test.ts`；实际检查节点跳转、缩放、适应画布、页面列表及 Markdown 导出中的引用清单 | [Graph](../../../../../src/Docs/Heartbeat.Docs/content/docs/start/graph.mdx)、[文档站 README · Graph](../../../../../src/Docs/Heartbeat.Docs/README.md#graph) | 图只包含 `graphSections` 选定分区的页面链接，章节归到页面 |
| Web 控制台（独立 SPA） | `src/Clients/Heartbeat.Web` 目录 `npm run dev`（5173，`/api` 代理到 8080，`?source=demo` 用演示数据）；`hb env up web` 后的统一入口 <http://localhost:8081>；路由 `/?view=ecg\|bubble\|strip\|ring&observer=`、`/entities/$entityId`、`/versions/$versionId`、`/schemas` | `hb verify full` 或变更选择的 `frontend-verify`，即目录内 `npm run verify`（typecheck + eslint --max-warnings=0 + prettier --check + vitest + vite build）；`npm run test:e2e` 用演示数据源跑 Playwright（首次 `npx playwright install chromium`）；`hb env up web` 后另跑 `npm run test:e2e:edge`，检查边缘转发、同源 /api、HMR，并提交真实数据检查四种视图和实体页；页面或交互变更另实际检查页面，浅色和深色都看 | [API](../../../../../src/Docs/Heartbeat.Docs/content/docs/api/index.mdx)、[前端 README](../../../../../src/Clients/Heartbeat.Web/README.md) | 默认 e2e 不连后端，演示数据每次加载重新生成；edge 用例依赖运行中的 Web 控制台和 API，会写入并删除测试实体；写入靠 2 秒轮询发现，事实时间远离今天的补发不在“现在”出现 |
| 测试 Case 与报告 | `/testing/observers/foreground-submission`、`/testing/reports/integration` | 文档目录 `pnpm test`、类型检查与构建；实际 Case 正文、结果关联、多参数结果、无匹配结果、报告搜索、筛选、详情和无报告状态 | [ADR · 开发验证与测试证据](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/verification.mdx)、[文档站 README](../../../../../src/Docs/Heartbeat.Docs/README.md) | 展示真实 TUnit JSON；页面不执行测试 |
| 本地环境 | `hb env up/down/status/logs/otel/restart/volumes` 和看板；表结构与迁移不一致时 `hb env up --reset` 重建默认卷 | 工具测试；`hb verify scenarios environment` 验证转发、部分启动、迁移失败、停止与数据保留；临时卷环境中检查 Playground、热更新和页面 | [Heartbeat.Dev README · 环境](../../../../../tools/Heartbeat.Dev/README.md#环境)、[AppHost README](../../../../../tools/Heartbeat.AppHost/README.md)、[ADR · 开发环境的启动与隔离](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/development-environment.mdx)、[ADR · 后端运行与本地环境 · 本地环境](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/backend-runtime.mdx#local-environment)、[ADR · 后端运行与本地环境 · HTTP 入口](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/backend-runtime.mdx#http-entry) | 本地验证不证明部署环境；停止保留数据库卷；API 三类 OTLP 遥测需实际读取看板或遥测 API |
| API 遥测 | API 启动时的 `OTEL_EXPORTER_OTLP_ENDPOINT` 与开发看板 `api` | `TelemetryTests`；`hb env up api --temp` 后用 `hb env otel` 和看板读取结构化日志、HTTP/数据库追踪和 HTTP/.NET 指标；无 OTLP 配置的独立运行 | [ADR · 后端运行与本地环境 · 遥测](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/backend-runtime.mdx#telemetry)、[API README](../../../../../src/Backend/Heartbeat.Api/README.md#遥测)、[AppHost 验证](../../../../../tools/Heartbeat.AppHost/README.md#api-遥测验证) | 只覆盖 API 遥测，不覆盖生产监控、浏览器或容器自身遥测 |
| 开发验证 | `hb verify full`、`hb verify changed [--quality]`、`hb verify scenarios` | `--plan` 核对选择和场景前提；执行后检查清单、结果和日志；失败、取消和场景跳过的边界测试 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md)、[ADR · 开发验证与测试证据](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/verification.mdx) | 运行时行为由场景检查；热更新与页面检查另行选择 |
| 质量与规模 | `hb quality --base REF`、`hb loc` | 分类与发现解析测试；真实扫描；可编译隔离基线验证变化比较 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md)、[ADR · 开发验证与测试证据](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/verification.mdx) | 发现供审查；扫描失败仍失败；历史编译失败不能称为比较通过 |
| 验证证据 | `hb artifacts list/prune` | 成功、失败、取消的清单与日志；保留并集、预览和删除验证 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md) | 清理验证使用临时证据目录，不操作用户历史数据 |
