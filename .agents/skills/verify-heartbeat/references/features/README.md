# Heartbeat Feature Map

本页用于选择验证入口。行为以链接的长期文档为准。表中的 Heartbeat.Dev 命令省略了前缀 `dotnet run --project tools/Heartbeat.Dev --`。

| 能力 | 用户入口 | 验证入口 | 权威文档 | 证据限制 |
| --- | --- | --- | --- | --- |
| 模型规则 | `dotnet test --project tests/Heartbeat.Model.Tests/Heartbeat.Model.Tests.csproj` | `verify full`、变更选择的 `model-tests` | [测试分工](../../../../../src/Docs/Heartbeat.Docs/content/docs/testing/index.mdx) | 规则检查无需数据库；不覆盖采集器运行与数据库 |
| 实体 API | 固定模型 `PUT /api/entities/{observers|observations|schemas}/{id}`、业务实体 `PUT /api/entities/{resourceName}/{id}`、`GET /api/entities/{id}` | `verify full` 或变更选择的集成测试；另检查直接维护的 OpenAPI 契约与对应接口页 | [实体协议](../../../../../src/Docs/Heartbeat.Docs/content/docs/api/index.mdx)、[存储约定](../../../../../src/Docs/Heartbeat.Docs/content/docs/storage/index.mdx)、[测试边界](../../../../../src/Docs/Heartbeat.Docs/content/docs/testing/index.mdx) | 真实 API 宿主和独立 PostgreSQL；不覆盖浏览器或部署 |
| 前台状态 Observer（macOS） | `dotnet run --project src/Observers/Heartbeat.Observer.ForegroundState`；`--api`、`--identity-file`、`--applications-file`、`--state-file` 选择服务、身份与状态文件；`--samples` 限定验证次数 | `verify full` 或变更验证；另在 macOS 用临时身份文件和独立 API、数据库运行并读回 | [Foreground State](../../../../../src/Docs/Heartbeat.Docs/content/docs/observers/application-activity/index.mdx)、[运行说明](../../../../../src/Observers/Heartbeat.Observer.ForegroundState/README.md)、[ADR · Observer 的责任与提交](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/observer-responsibility.mdx) | 自动测试覆盖应用身份、时段边界、事件和休眠边界、Outbox 恢复及六实体读回；实际运行另验证 macOS 读取与切换，真实休眠需另测 |
| 文档站 | `aspire run` 或 `aspire start`，或者文档目录 `pnpm dev`；文档端口的 `/core`、`/observers`、`/api`、`/storage`、`/testing`、`/adr` | 文档目录 `pnpm docs:check`、`pnpm test`、`pnpm types:check`、`pnpm build`；实际页面、搜索、导出与资源链接 | [文档站 README](../../../../../src/Docs/Heartbeat.Docs/README.md)、[ADR · 文档的权威与传播](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/documentation-authority.mdx)、仓库根目录的 [AGENTS.md](../../../../../AGENTS.md) | 页面检查只证明所检查的页面和交互 |
| Web 控制台（独立 SPA） | `src/Frontend/Heartbeat.Web` 目录 `npm run dev`（5173，`/api` 代理到 8080）；Aspire 统一入口 <http://localhost:8081>；路由 `/`、`/entities/$id?view=graph|inspect|pulse`、`/compose` | `verify full` 或变更选择的 `frontend-verify`，即目录内 `npm run verify`（typecheck + eslint --max-warnings=0 + prettier --check + vitest + vite build）；`npm run test:e2e` 跑 Playwright（首次 `npx playwright install chromium`）；Aspire 环境下另跑 `npm run test:e2e:edge` 验证 8081 边缘转发、同源 /api 与 HMR；页面或交互变更另实际检查页面 | [实体协议](../../../../../src/Docs/Heartbeat.Docs/content/docs/api/index.mdx)、[前端 README](../../../../../src/Frontend/Heartbeat.Web/README.md) | 后端当前仅有 `GET/PUT /entities`，前端以单实体 ID 为入口沿引用展开；列表/搜索能力随后端接口演进；默认 e2e 不连真实数据库，edge 用例依赖完整 Aspire 环境 |
| 测试 Case 与报告 | `/testing/entity-schemas/table-creation-failure`、`/testing/reports/integration` | 文档目录 `pnpm test`、类型检查与构建；实际 Case 正文、结果关联、多参数结果、无匹配结果、报告搜索、筛选、详情和无报告状态 | [ADR · 开发验证与测试证据](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/verification.mdx)、[文档站 README](../../../../../src/Docs/Heartbeat.Docs/README.md) | 展示真实 TUnit JSON；页面不执行测试 |
| 本地环境 | `aspire run/start/stop/describe/logs/resource` 和看板 | 工具测试；独立 Aspire 环境、端口和数据卷验证启动顺序、就绪、停止、数据保留、代理与热更新 | [AppHost README](../../../../../tools/Heartbeat.AppHost/README.md)、[ADR · 后端运行与本地环境 · 本地环境](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/backend-runtime.mdx#local-environment)、[ADR · 后端运行与本地环境 · HTTP 入口](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/backend-runtime.mdx#http-entry) | 本地验证不证明部署环境；停止保留数据库卷；API 三类 OTLP 遥测需实际读取看板或遥测 API |
| API 遥测 | API 启动时的 `OTEL_EXPORTER_OTLP_ENDPOINT` 与开发看板 `api` | `TelemetryTests`；独立 Aspire 环境读取结构化日志、HTTP/数据库追踪和 HTTP/.NET 指标；无 OTLP 配置的独立运行 | [ADR · 后端运行与本地环境 · 遥测](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/backend-runtime.mdx#telemetry)、[API README](../../../../../src/Backend/Heartbeat.Api/README.md#遥测)、[AppHost 验证](../../../../../tools/Heartbeat.AppHost/README.md#api-遥测验证) | 只覆盖 API 遥测，不覆盖生产监控、浏览器或容器自身遥测 |
| 开发验证 | `verify full`、`verify changed [--quality]` | `--plan` 核对选择；执行后检查清单、结果和日志；失败和取消边界测试 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md)、[ADR · 开发验证与测试证据](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/verification.mdx) | 容器运行与页面检查另行选择 |
| 质量与规模 | `quality --base REF`、`loc` | 分类与发现解析测试；真实扫描；可编译隔离基线验证变化比较 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md)、[ADR · 开发验证与测试证据](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/verification.mdx) | 发现供审查；扫描失败仍失败；历史编译失败不能称为比较通过 |
| 验证证据 | `artifacts list/prune` | 成功、失败、取消的清单与日志；保留并集、预览和删除验证 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md) | 清理验证使用临时证据目录，不操作用户历史数据 |
