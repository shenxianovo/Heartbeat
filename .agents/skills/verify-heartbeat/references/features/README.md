# Heartbeat Feature Map

本页用于选择验证入口，行为语义以链接的长期文档为准。Developer CLI 命令前加 `dotnet run --project tools/Heartbeat.Dev --`。

| 能力 | 用户入口 | 验证入口 | 权威文档 | 证据限制 |
| --- | --- | --- | --- | --- |
| 模型规则与场景映射 | `dotnet test --project tests/Heartbeat.Model.Tests/Heartbeat.Model.Tests.csproj` | `verify full`、变更选择的 `model-tests`；集成测试另复用场景读回 | [100 场景验证](../../../../../src/Docs/Heartbeat.Docs/content/docs/testing/model-generality/index.mdx) | 规则检查无需数据库；来源接入、历史与查询不能从类型通过推出 |
| 实体 API | 固定模型 `PUT /api/entities/{observers|observations|schemas}/{id}`、业务实体 `PUT /api/entities/{resourceName}/{id}`、`GET /api/entities/{id}` | `verify full` 或变更选择的集成测试；另检查直接维护的 OpenAPI 契约与对应接口页 | [实体协议](../../../../../src/Docs/Heartbeat.Docs/content/docs/api/index.mdx)、[存储约定](../../../../../src/Docs/Heartbeat.Docs/content/docs/storage/index.mdx)、[测试边界](../../../../../src/Docs/Heartbeat.Docs/content/docs/testing/index.mdx) | 真实 API 宿主和独立 PostgreSQL；不覆盖浏览器或部署 |
| 前台状态 Observer（macOS） | `dotnet run --project src/Observers/Heartbeat.Observer.ForegroundState`；`--api`、`--identity-file`、`--applications-file`、`--state-file` 选择服务、身份与状态文件；`--samples` 限定验证次数 | `verify full` 或变更验证；另在 macOS 用临时身份文件和独立 API、数据库运行并读回 | [观测语义](../../../../../src/Docs/Heartbeat.Docs/content/docs/observers/foreground-state.mdx)、[运行说明](../../../../../src/Observers/Heartbeat.Observer.ForegroundState/README.md)、[主体与身份职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0002-observer-capabilities-and-platform-clients.mdx) | 自动测试覆盖应用身份、时段边界、事件和休眠边界、Outbox 恢复及六实体读回；实际运行另验证 macOS 读取与切换，真实休眠需另测 |
| Sources Observer（原生来源） | `dotnet run --project src/Observers/Heartbeat.Observer.Sources -- --help` | `verify full`；Model.Tests 原生解析/SQLite/CLI；Integration.Tests 来源流水线；另做限定本地采集 | [来源接入](../../../../../src/Docs/Heartbeat.Docs/content/docs/observers/sources/index.mdx)、[运行说明](../../../../../src/Observers/Heartbeat.Observer.Sources/README.md) | 100 场景目录分开记录原生支持与语义证据；离线导入不证明在线账号同步；Aspire 仍须 Docker 单独验证 |
| 文档站 | 文档端口 `/core`、`/observers` 及观测定义、API 概览 `/api`、ADR | 文档目录 `pnpm types:check`、`pnpm build`；实际页面、搜索、导出与资源链接 | [文档站 README](../../../../../src/Docs/Heartbeat.Docs/README.md)、[应用时段 Schema](../../../../../src/Docs/Heartbeat.Docs/content/docs/observers/schemas/foreground-application-interval.mdx)、[文档入口责任](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0001-documentation-source-of-truth.mdx) | 页面检查只证明所检查的页面和交互 |
| 测试 Case 与报告 | `/testing/entity-schemas/table-creation-failure`、`/testing/reports/integration` | 文档目录 `pnpm test`、类型检查与构建；实际 Case 正文、结果关联、多参数结果、无匹配结果、报告搜索、筛选、详情和无报告状态 | [报告职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0007-developer-cli-and-verification.mdx)、[文档站 README](../../../../../src/Docs/Heartbeat.Docs/README.md) | 展示真实 TUnit JSON；页面不执行测试 |
| 本地环境 | `aspire run/start/stop/describe/logs/resource` 和看板 | 工具测试；独立 Aspire 环境、端口和数据卷验证启动顺序、就绪、停止、数据保留、代理与热更新 | [AppHost README](../../../../../tools/Heartbeat.AppHost/README.md)、[启动职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0005-backend-project-organization.mdx#本地启动)、[编排职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0008-aspire-local-development.mdx)、[HTTP 入口](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0006-unified-http-entry.mdx) | 本地验证不证明部署环境；停止保留数据库卷，调用链与指标需额外接入 |
| 开发验证 | `verify full/changed/closeout` | `--plan` 核对选择；执行后检查清单、结果和日志；失败和取消边界测试 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md)、[职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0007-developer-cli-and-verification.mdx) | 容器运行与页面检查另行选择 |
| 质量与规模 | `quality --base REF`、`quality loc` | 分类与发现解析测试；真实扫描；可编译隔离基线验证变化比较 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md)、[质量职责](../../../../../src/Docs/Heartbeat.Docs/content/docs/adr/0007-developer-cli-and-verification.mdx) | 发现供审查；扫描失败仍失败；历史编译失败不能称为比较通过 |
| 验证证据 | `artifacts list/prune` | 成功、失败、取消的清单与日志；保留并集、预览和删除验证 | [工具 README](../../../../../tools/Heartbeat.Dev/README.md) | 清理验证使用临时证据目录，不操作用户历史数据 |
