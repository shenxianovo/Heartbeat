# 对象（Object）

[返回阅读树](../../HUMAN.md) · [系统目标与基本约定](../../HUMAN.md#基本约定)

## 含义

**对象**是可以被指认的事物。

电脑、电脑上的具体应用、账号和观测工具均可作为对象。系统根据已有观测建立具体对象的指认。

## 属性

| 节点 | 问题 | 必要性 |
| --- | --- | --- |
| [身份（Identity）](identity.md) | 信息是否涉及同一个事物？ | 联系同一事物的观测，区分不同事物 |
| [角色（Role）](roles.md) | 对象怎样参与观测？ | 区分对象的参与作用 |

对象身份的[程序表示与创建约定](identity.md#对象身份的程序表示与创建)见身份节点。
