# 对象发现（ObjectDiscovery）

[返回推导](README.md) · [返回阅读树](../../HUMAN.md)

## 含义

**对象发现**是根据观测建立对象指认的过程。

对象指认（ObjectIdentification）是对象发现形成的推导结果。

对象发现采用观测中的原始名称、标识、描述及其他识别依据。对象发现判断这些信息指向哪个对象，以及不同观测是否涉及同一个对象。

判断可以随新证据修正。原始观测信息予以保留。

**例：可见的应用与未知的账号。** 采集器能识别电脑上的 QQ 应用 A，却无法取得账号或登录信息。

系统可以建立 A 的对象指认。账号及登录状态保持未知。系统不创建账号对象或登录关系。缺少登录关系的观测依据，不能据此判断 A 未登录。

## 程序流程

对象发现根据观测依据，决定怎样建立观测与对象的关联。

| 已有依据 | 程序行为 |
| --- | --- |
| 能关联到已有对象 | 复用该对象身份 |
| 足以指认一个具体事物，尚未关联到已有对象 | 创建新的对象表示，并建立关联 |
| 不足以指认具体事物 | 保留观测和未知，不创建对象 |

新建的是程序中的对象表示。不同表示是否指向同一事物，由同一性判断确定。判断可以随新证据修正。

对象发现负责建立观测与对象的关联。[对象创建](../objects/identity.md#对象身份的程序表示与创建)负责分配身份。
