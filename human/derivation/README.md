# 推导（Derivation）

[返回阅读树](../../HUMAN.md) · [系统目标与基本约定](../../HUMAN.md#基本约定)

## 含义

**推导**是根据观测或已有推导结果，按明确方式形成新信息的过程。

## 属性

| 节点 | 问题 | 必要性 |
| --- | --- | --- |
| [推导依据（DerivationInput）](input.md) | 实际采用了哪些信息？ | 明确结果采用的依据 |
| [推导方式（DerivationMethod）](method.md) | 怎样从依据形成结果？ | 说明解释和组合信息的规则 |
| [推导结果（DerivedResult）](result.md) | 得到了什么信息？ | 区分形成的理解与原观测 |
