# 实体（Entity）

[返回阅读树](../../HUMAN.md) · [系统目标与基本约定](../../HUMAN.md#基本约定)

## 含义

**实体**是可以被指认的事物。

电脑、电脑上的具体应用、账号和观测工具均可作为实体。系统根据已有观测建立具体实体的指认。

## 属性

| 节点 | 问题 | 必要性 |
| --- | --- | --- |
| [身份（Identity）](identity.md) | 信息是否涉及同一个事物？ | 联系同一事物的观测，区分不同事物 |

实体身份的[程序表示与创建约定](identity.md#实体身份的程序表示与创建)见身份节点。

## 程序契约

实体通过 [`IEntity`](../program/README.md#核心接口) 提供稳定的 `EntityId Id`。`EntityId` 包装 UUIDv7。当前不建立实体共同父类。

观测也是实体，观测标识与该观测的实体标识相同。
